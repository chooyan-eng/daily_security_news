# Accenture、35GBのソースコード等窃取を主張するハッカーの投稿を受けて侵害を確認

- **日付**: 2026-07-09
- **出典**: [Help Net Security](https://www.helpnetsecurity.com/2026/07/08/accenture-data-breach-2026/)
- **トピック**: [Accenture データ侵害・ソースコード流出（2026年7月）](../topics/accenture-data-breach-2026.md)
- **分類**: 新規

## 概要

ハンドルネーム「888」を名乗る攻撃者が2026年7月、サイバー犯罪フォーラムPwnForumsにおいて、Accentureから約35GBのソースコードを含むデータを窃取したと主張し販売を持ちかけた。Accentureは「限定的な事案」を認識し、侵害源を「修復済み」と説明したが、データ窃取の有無については明言していない。事業・サービス提供への影響はないとしている。

## 詳細

投稿された「広告」には、Accenture関連ドメインに紐づく本番用URLのプライベートAzure DevOpsリポジトリからデータを窃取したことを示すスクリーンショットが証拠として添付されていた。攻撃者はソースコード、RSA鍵、SSH鍵、Azure個人アクセストークン、Azure Storageアクセスキー、各種設定ファイルを窃取したと主張しており、これらは真正であればAccentureの内部システムや顧客環境への横展開に悪用され得る機密性の高い認証情報群である。

Accentureの広報担当者はHelp Net Securityの取材に対し、「この限定的な事案を認識しており、発生源については修復を行った」とコメントしたが、具体的なデータ窃取の規模や内容については確認も否定もしていない。同社はまた、Accentureの事業運営およびサービス提供には影響がなかったとしている。

なお「888」は過去にも2024年6月、Accentureの現従業員・元従業員32,826名分のデータ窃取を主張して販売を試みた実績があるが、その際Accentureは「データセットには氏名とAccentureのメールアドレスの3件分しか含まれていなかった」として、実害は限定的だったと説明している。今回のケースでは、Azure DevOpsという開発基盤からソースコードや認証鍵が窃取されたと主張されている点で、サプライチェーンリスクの観点からより深刻度が高い可能性がある。

本件は現時点で被害の全容が確定しておらず、Accentureのクライアント企業への波及可能性を含め、今後の推移が注視される。
