# 「CosmosEscape」：Azure Cosmos DBのゲートウェイ脆弱性により全データベースへアクセス可能なマスターキーが露出

- **日付**: 2026-07-30
- **出典**: [The Hacker News](https://thehackernews.com/2026/07/azure-cosmos-db-flaw-exposed-platform.html)
- **トピック**: [CosmosEscape：Azure Cosmos DB プラットフォーム全体キー露出脆弱性（2026年）](../topics/cosmosescape-azure-cosmos-db-2026.md)
- **分類**: 新規

## 概要

Wiz Researchは、Microsoft Azure Cosmos DBのゲートウェイ層に存在した脆弱性「CosmosEscape」を公表した。同脆弱性を悪用することで、テナントの境界を越えてAzure Cosmos DB上の任意のデータベースにアクセス可能なプラットフォーム全体のマスターキーを取得できたという。Microsoftは2025年11月に一次修正を適用し、2026年7月までに全リージョンへの恒久対応を完了している。

## 詳細

### 脆弱性の概要

Wiz Researchは、Azure Cosmos DBのゲートウェイコンポーネントを侵害することで、Cosmos DBサービス全体で共有される内部的なキーを取得できることを発見した。このキーを用いることで、本来アクセス権限のない他テナントのCosmos DBデータベースに対しても読み書きアクセスが可能になるという、クロステナントでの権限昇格が成立する脆弱性であった。

### 発見から修正までの経緯

- 2025年11月20日: Wiz ResearchがMicrosoftに脆弱性を報告
- 2025年11月22日: Microsoftが暫定的なホットフィックスを展開
- 2026年7月: 恒久的な修正を全リージョンへ展開完了
- 2026年7月30日: Wiz Researchが詳細を公開

### 影響範囲

Cosmos DBはAzure上で多数のWebアプリケーション・SaaSサービスのバックエンドデータストアとして利用されている。ゲートウェイ層で発行される鍵がサービス全体で共有される設計であったことが根本原因とされ、悪用が成立していた場合、単一テナントの侵害が他のあらゆる顧客のデータベースへの侵害に波及し得る、プラットフォーム全体に関わる深刻な脆弱性であった。

### Microsoftの対応

Microsoftは修正が完了しているため、顧客側での追加対応は不要（no action required）としている。ただし、修正完了までの期間における不正利用の痕跡有無については、Wizの報告およびMicrosoft側の調査結果を踏まえた継続的な情報収集が望まれる。

### クラウドマネージドDBサービスへの示唆

本件は、マルチテナント型のクラウドデータベースサービスにおいて、ゲートウェイ・プロキシ層の実装不備が単一顧客の侵害にとどまらずプラットフォーム全体の顧客データへ波及するリスクを示す事例である。Webアプリケーションのバックエンドとしてマネージド型クラウドDBを利用する事業者にとって、プラットフォーム側のアーキテクチャリスクを把握しておく重要性を示している。
