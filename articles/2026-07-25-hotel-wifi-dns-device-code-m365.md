# ホテルWi-FiのDNSハイジャックでMicrosoft 365アカウントを乗っ取るキャンペーンが拡大

- **日付**: 2026-07-25
- **出典**: [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-hijack-hotel-wi-fi-dns-to-steal-microsoft-365-accounts/)
- **トピック**: [デバイスコードフィッシング / AiTM セッショントークン窃取（2026年）](../topics/device-code-phishing-aitm-2026.md)
- **分類**: 続報

## 概要

ホテルや会議施設のWi-FiゲートウェイのDNS設定を改ざんし、出張中の従業員のMicrosoft 365ログインをOAuthデバイスコードフローの悪用にすり替えることでMFAを回避しアカウントを乗っ取るキャンペーンが確認された。米国複数都市、インド、サウジアラビアで観測されている。

## 詳細

ReliaQuestなどの調査によると、本キャンペーンは少なくとも2026年6月から活動しており、フィッシングメールや端末侵害を伴わずにホテル・会議施設の共有Wi-Fiゲートウェイを直接標的とする点が特徴。攻撃者は露出した管理サービスや脆弱な認証情報を悪用してゲートウェイの管理アクセス権を取得し、DNS設定を改ざんして、利用者がMicrosoft 365にログインしようとした際の通信を攻撃者インフラへリダイレクトする。

リダイレクト先では、Microsoftのデバイスコード認証フロー（Device Authorization Grant）が悪用される。利用者が正規のログイン画面と誤認して攻撃者主導のリクエストを承認してしまうと、正規のOAuthトークンが攻撃者のクライアントに対して発行される。この手法はパスワードの窃取や既存アクセストークンの傍受を伴わずに成立するため、多要素認証（MFA）による防御を実質的に無効化する。

被害は金融サービス、法律、ヘルスケア、エネルギー、小売、専門サービスなど幅広い業種の組織に及んでおり、地理的には米国内複数都市に加えインド・サウジアラビアでも確認されている。研究者は本キャンペーンの手口がロシア系国家支援ハッカー集団APT28が過去に用いた手法と類似していると指摘するが、明確な帰属には至っていない。

本件は、2026年6月にトピック化した「デバイスコードフィッシング / AiTM」の攻撃手法（37倍の検出急増、犯罪エコシステムでのコモディティ化）が実際のインフラ（公衆Wi-Fiゲートウェイ）を悪用する形で具体化した続報にあたる。有効な対策として、企業端末での常時フルトンネルVPNの強制適用（DNSを含む全通信を企業ネットワーク経由にする）が挙げられている。
