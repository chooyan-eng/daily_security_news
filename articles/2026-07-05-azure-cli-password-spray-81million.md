# Azure CLIを狙った8100万回超のパスワードスプレー攻撃、78アカウントが侵害

- **日付**: 2026-07-05
- **出典**: [The Hacker News](https://thehackernews.com/2026/07/azure-cli-password-spray-hits-at-least.html)
- **トピック**: [Azure CLI パスワードスプレー攻撃キャンペーン「LSHIY」（2026年）](../topics/azure-cli-password-spray-lshiy-2026.md)
- **分類**: 新規

## 概要

セキュリティ企業Huntressは、Microsoft Azure CLI を標的とした大規模かつ自動化されたパスワードスプレー攻撃キャンペーンを観測した。インターネットインフラ事業者LSHIY LLC（AS32167）が管理するIPv6アドレス範囲を発信源とし、2026年6月12日から26日の2週間で8100万回超のログイン試行が行われ、64組織にわたる少なくとも78件のMicrosoftアカウントが侵害された。攻撃は非推奨のOAuthフロー「ROPC」を悪用し、条件付きアクセスポリシー（CAP）によるMFA保護を回避していた。

## 詳細

### 攻撃の規模

Huntressは2026年6月12日から26日までの間に、Azure CLIを標的とした8100万回超のログイン試行を確認した。攻撃は自動化されており、既知の侵害済みユーザー名・パスワードの組み合わせ（ローテーションされていない過去の漏洩情報）を重点的に利用していた。64組織にわたって少なくとも78件のMicrosoftアカウントが実際に侵害されている。

### 攻撃手法：ROPCによるMFAバイパス

攻撃者は、Resource Owner Password Credentials（ROPC）と呼ばれる非推奨のOAuthフローを悪用し、条件付きアクセスポリシー（Conditional Access Policy, CAP）による保護を回避した。MFAを導入している組織であっても、Azure CLIのROPCログインに対してMFAが適用・強制されていないケースが多く、特定のアプリのみにMFAを強制する設定や、そもそもAzure CLI経由のログインがMFA適用対象から漏れているケースが悪用された。

### 攻撃発信元

攻撃トラフィックは、インターネットインフラ事業者LSHIY LLC（AS32167）が管理するIPv6アドレス範囲から発信されていることが確認された。

### 広がるクレデンシャルスプレー攻撃の傾向

Huntressは、顧客基盤全体でクレデンシャルスプレー攻撃の量が155倍以上に急増していることも観測しており、特に5月下旬から6月上旬にかけて急増した。Huntressが保護するテナントあたり月平均約1,964件の失敗試行が記録されている。

### 対策推奨

- Azure CLIを含むレガシー認証プロトコル（ROPCなど）の無効化
- 条件付きアクセスポリシーがすべてのログイン経路（CLI、レガシープロトコル含む）を確実にカバーしているか再点検
- 過去に漏洩したことのある認証情報の強制ローテーション
- Azure AD Identity Protectionでの異常なサインイン試行の監視強化
- 可能な限り、パスワードレス認証（FIDO2等）への移行を検討
