# Accenture、ハッカーによるデータ販売主張を受けて侵害を確認

- **日付**: 2026-07-12
- **出典**: [BleepingComputer](https://www.bleepingcomputer.com/news/security/accenture-confirms-breach-after-hacker-offers-stolen-data-for-sale/)
- **トピック**: [Accenture データ侵害・ソースコード窃取主張（2026年7月）](../topics/accenture-breach-source-code-2026.md)
- **分類**: 新規

## 概要

コンサルティング大手Accentureが、ハッカーフォーラム上で「888」を名乗る攻撃者による35GBのデータ窃取主張を受け、侵害を確認したと発表した。窃取されたと主張されるデータにはAzureアクセスキー、設定ファイル、RSA/SSH鍵、ソースコードが含まれる。同攻撃者はDecathlon、Credit Suisse、Shell、Heineken、UNICEFへの侵害主張歴を持つ。

## 詳細

### 事案の経緯

ハッカーフォーラム「PwnForums」上で、「888」を名乗る脅威アクターがAccentureへの侵入と35ギガバイトのデータ窃取を主張し、そのデータの販売を持ちかけたことから事案が発覚した。主張によれば、窃取されたデータにはAzureのアクセスキー・トークン、各種設定ファイル、RSAおよびSSHの鍵、そしてソースコードが含まれるとされる。

Accentureは声明で「これは限定的な事案であると認識しており、原因はすでに是正済みである。Accentureの業務およびサービス提供への影響はない」とコメントした。ただし、攻撃者が主張するデータの量や種類について、同社は具体的なコメントを避けている。

### 攻撃者の背景

「888」を名乗る攻撃者は過去にもDecathlon、Credit Suisse、Shell、Heineken、UNICEFなど複数の大手グローバル企業・組織への侵害を主張してきた実績があるとされる。同一犯である場合、企業のクラウド環境やソースコードリポジトリを標的とした情報窃取・転売を専門とする脅威アクターである可能性が高い。

### リスクと影響

Azureアクセスキーやソースコードが実際に流出していた場合、それらを悪用した二次的な侵害（クライアント環境への横展開、内部システムへの不正アクセス、ソースコード内に含まれる可能性のあるハードコードされた認証情報の悪用等）のリスクが懸念される。Accentureは世界有数のITコンサルティング・システムインテグレーション企業であり、多数の大企業・政府機関のクライアントを抱えることから、サプライチェーンリスクとしての影響範囲が注視されている。

### 今後の対応

Accentureは詳細な被害範囲について現時点で公表していないが、今後の調査進展により影響を受けたクライアントへの通知や追加の技術的詳細が公開される可能性がある。
