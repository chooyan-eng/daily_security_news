# GitLab セルフホスト版に未修正時代の完全RCEチェーン公開 — Oj JSONパーサーのメモリ破壊を悪用

- **日付**: 2026-07-26
- **出典**: [The Hacker News](https://thehackernews.com/2026/07/researcher-publishes-gitlab-rce-poc.html)
- **トピック**: [GitLab Oj gem ヒープリーク連鎖RCE（2026年）](../topics/gitlab-oj-heap-leak-rce-2026.md)
- **分類**: 続報
## 概要

セキュリティ研究チーム depthfirst が、GitLab が6月10日に修正済みの脆弱性を悪用する動作可能なエクスプロイトコードを7月24日に公開した。自己ホスト型 GitLab 18.11.3 以下の未パッチ環境で、プロジェクトへのプッシュ権限を持つ認証済みユーザーが git ユーザー権限でコマンドを実行できる。CVE番号は未割り当て。

## 詳細

### 攻撃チェーンの概要

depthfirst の研究によれば、脆弱性の根本原因は GitLab が内部で利用する Ruby 用 JSON パーサーライブラリ「Oj」に存在する2件のメモリ破壊バグである。攻撃者はまず、細工した Jupyter Notebook ファイルをプロジェクトにコミットし、その差分（diff）表示画面を開かせることでヒープポインタの値をリークさせる。この情報漏洩を複数回繰り返すことで、自動化されたプローブがプロセスメモリ上のライブラリの配置位置を特定できるようになる。ライブラリのアドレスが判明した後、さらに2つの追加 Notebook を用いて最終的なペイロードを発火させ、任意コード実行に至る。

### 影響バージョンと修正状況

影響を受けるのは GitLab CE/EE の 15.2.0〜18.10.7、18.11.0〜18.11.4、19.0.0〜19.0.1 で、全エディション・全ティアが対象となる。修正版は 18.10.8、18.11.5、19.0.2。GitLab は6月10日の時点でこの問題を修正していたが、CVE識別子を要求しておらずCVSSスコアも付与されていないため、多くの組織が深刻度を把握できないまま未パッチの状態が続いていたとみられる。

### Oj ライブラリの広範な影響

今回のチェーンで利用された2件のパーサーバグに加え、depthfirst による Oj ライブラリ全体のレビューでは、パーサー・ローダー・ダンパー・ドキュメントAPIにまたがる合計9件のセキュリティアドバイザリが新たに公開されている。Oj は GitLab 以外にも多数の Ruby アプリケーションで利用されているため、同種の脆弱性が他のRuby製Webアプリケーションにも波及する可能性がある。

### リスクと対策

CVEが存在しないためスキャナーやパッチ管理システムで検知されにくく、自己ホスト型 GitLab を運用する組織はバージョン確認を個別に行う必要がある。プロジェクトへの書き込み権限を持つ内部関係者や、侵害されたコントリビューターアカウントからの攻撃が現実的な脅威となる。速やかに 18.10.8 / 18.11.5 / 19.0.2 以降へのアップグレードが推奨される。
