# AI安全性評価団体METR、盗難APIキーで60万ドル相当のAIクレジットを3週間気づかず消費される

- **日付**: 2026-09-03
- **出典**: [The Hacker News](https://thehackernews.com/2026/09/attackers-steal-metr-api-key-and.html), [The Register](https://www.theregister.com/security/2026/09/01/attacker-stole-a-metr-api-key-used-600k-worth-of-credits-and-no-one-noticed-for-weeks/), [Infosecurity Magazine](https://www.infosecurity-magazine.com/news/attackers-steal-metr-api-key/)
- **分類**: 新規

## 概要

AIモデルの安全性評価を行う非営利団体METRは、研究者の公開EC2インスタンスの設定不備を突かれてモデル推論用APIキーを窃取され、攻撃者が約3週間にわたり時価60万ドル相当のAIクレジットを消費していたことを公表した。不正利用が正規の評価トラフィックと区別しにくかったことが、長期間発覚しなかった一因とされる。

## 詳細

METRが公開したセキュリティアップデートによると、2026年3月、研究者が運用する公開アクセス可能なEC2インスタンスに存在した「フェイルオープン」バグにより、意図せず認証機能が無効化された状態になっていた。攻撃者は、言語モデルやAIエージェントに関連する高シグナルな語を含む新規登録サイトを、証明書透明性（Certificate Transparency）ログをスキャンして探索する手法でこのインスタンスを発見したとみられている。

攻撃者はインスタンス上で稼働していたAIエージェントに指示を与え、モデルプロバイダーのAPIキーを引き出させたうえで、持続的アクセスのためのSSH鍵を追加。窃取した認証情報を用いて、約3週間にわたり大量のモデルクレジットを消費し続けた。

不正利用が長期間発覚しなかった背景には、METRの研究者が業務上日常的に大量のモデルトラフィックを生成していたため、不正な利用を通常業務と区別することが困難だったという事情がある。また、無償提供されていたクレジットには支出上限の設定機能がなかったことも一因とされる。消費された60万ドル相当のクレジットは、モデル提供元が無償で供与していたものであり、METR側に直接の金銭的損害が生じたわけではないが、商業的価値としては同額に相当する。

METRは事案発覚後、当該研究者のアクセス権を無効化し、認証情報をローテーション、対象端末を初期化したうえでモデル提供元に通知した。再発防止策として、可能な範囲でAPIキーに支出アラートを設定する対応も講じている。なお、METRは2026年5月にも、公開インフラに対する探索的な攻撃キャンペーンを受けていたことを別途明らかにしている。
