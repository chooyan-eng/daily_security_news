# Node.js、2026年7月のセキュリティリリースで11件の脆弱性を修正

- **日付**: 2026-07-29
- **出典**: [Node.js Blog](https://nodejs.org/en/blog/vulnerability/july-2026-security-releases)
- **トピック**: [Node.js 2026年7月セキュリティリリース](../topics/nodejs-security-release-july-2026.md)
- **分類**: 続報
## 概要

Node.js プロジェクトはインフラ障害により延期していたセキュリティリリースを2026年7月29日に公開し、稼働中の全ブランチ（22.x／24.x／26.x）にまたがる11件の脆弱性を修正した。v22.23.2・v24.18.1・v26.5.1 が公開され、HTTP/2処理、Permission Model、HTTPS接続、DNS解決、SQLite、Zlib、HTTPパーサーなど広範な領域が対象となった。

## 詳細

### リリース概要

Node.js は当初予定より遅れて2026年7月29日（水）に緊急セキュリティリリースを公開した。影響を受けるのはメンテナンス中の3系統（22.x、24.x、26.x）すべてで、それぞれ v22.23.2、v24.18.1、v26.5.1 として提供されている。合計10件のCVEに対応し、うち3件は高深刻度と評価されている。

### 主な脆弱性

- **Permission Model のバイパス**: `--permission` サンドボックスモデルにおいて、radix-tree のプレフィックス境界を跨いだファイルシステムアクセスが過剰に許可されてしまう不具合。Node.js の実験的なセキュリティ機能を回避される可能性がある。
- **HTTPS Agent の TLS セッション再利用問題**: 異なるIDポリシー間でホスト名検証をスキップしてTLSセッションを再利用してしまう不具合。中間者攻撃のリスクにつながる。
- **node:sqlite の不具合**: `DatabaseSync#createTagStore()` で作成された `StatementSyncIterator` がリセット・再バインド後も古いキャッシュ済みプリペアドステートメントを実行し続けてしまう問題。
- **HTTP/2 ルーティングおよびヒープメモリ管理**の高深刻度脆弱性で、サーバークラッシュ（DoS）につながる可能性がある。

### 影響と対応

Node.js はサーバーサイドJavaScriptランタイムとして極めて広範に利用されており、特にPermission Modelのバイパスやサーバークラッシュにつながる脆弱性はWebアプリケーションの可用性・機密性に直結する。利用者には速やかな最新パッチバージョンへの更新が推奨されている。
