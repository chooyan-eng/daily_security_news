# 脅威アクター「Satanic」、Stripe加盟店API鍵1,000件超を流出 ― 69万件近い顧客レコードが露出

- **日付**: 2026-08-18
- **出典**: [InfoStealers](https://www.infostealers.com/article/analyzing-stripe-breach-confirmed-vendor-exposure-and-claims-of-20000-compromised-apis/)
- **トピック**: [Stripe加盟店APIキー流出事案（2026年8月）](../topics/stripe-vendor-api-key-leak-2026.md)
- **分類**: 新規

## 概要

8月18日、サイバー犯罪フォーラム「pwnforums」上で、脅威アクター「Satanic」がStripe決済プラットフォームを利用する669の加盟店に関する情報と、1,033件のAPIキーを公開した。42カ国の加盟店にまたがる約68万8,363件の顧客レコードが露出したとみられる。Stripe自体の基盤が侵害されたわけではなく、個々の加盟店が保有するシークレットAPIキーが窃取され、Stripeの正規APIを通じてデータが取得されたとみられている。

## 詳細

### 事案の内容

流出は8月18日に「pwnforums」というダークウェブフォーラムで発生した。攻撃者「Satanic」は当初、669の加盟店に関する詳細情報と1,033件の侵害されたAPIキーを公開したが、その後、複数のプラットフォームにまたがり総計2万件のAPIキーが侵害されたと主張している。

### 手口

証拠が示すところによれば、Stripe自体のインフラが侵害されたわけではない。攻撃者は個々の加盟店が保有するシークレットAPIキーを何らかの方法で入手し、それを用いてStripeの正規APIエンドポイントから顧客・決済関連データを取得したとみられる。

### 流出データの範囲

流出データは17,654個のファイルにわたり、Stripe APIのエンドポイントを通じて取り出された顧客情報、請求（charges）、支払いインテント（payment intents）、Checkoutセッション、請求書（invoices）、payout情報、残高取引（balance transactions）、返金、チャージバック（disputes）、サブスクリプション、商品・価格情報などが含まれるとされる。影響は42カ国の加盟店にまたがり、推計68万8,363件の顧客レコードが露出した可能性がある。

### 脅威アクターについて

「Satanic」は、サイバー犯罪の分野で以前から知られる人物で、脅威インテリジェンス企業Hudson Rockの研究者によって大規模侵害への関与が過去に確認されている。

### リスクと注意点

Stripe基盤そのものではなく加盟店側のAPIキー管理の不備が原因とみられるため、Stripeを利用するEC事業者は、APIキーのローテーションや権限の最小化、シークレットのコード・リポジトリへの誤コミット防止などの対策強化が求められる。
