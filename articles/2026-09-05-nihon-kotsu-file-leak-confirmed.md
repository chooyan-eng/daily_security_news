# 日本交通への不正アクセス、保有ファイルの一部が外部流出と判明

- **日付**: 2026-09-05
- **出典**: [ScanNetSecurity](https://scan.netsecurity.ne.jp/article/2026/09/04/56132.html)
- **トピック**: [日本交通 不正アクセス・マルウェア感染（2026年）](../topics/nihon-kotsu-malware-breach-2026.md)
- **分類**: 続報

## 概要

タクシー大手・日本交通は2026年9月4日、7月に発生した不正アクセス・マルウェア感染事案について、外部専門機関との調査の結果、同社が保有していたファイルの一部が外部に流出していたことが判明したと発表した。個人情報の漏えいが確認された場合は該当者に速やかに通知するとしている。

## 詳細

日本交通では2026年7月11日未明に社内システムへの不正アクセスとマルウェア感染が発生し、7月13日に公表された。電話配車、ハイヤーWeb受注・予約管理システム、陣痛タクシーWeb登録フォームなどが影響を受け、タクシー配車アプリ「GO」（別会社運営）は影響を受けなかった。8月19日の第4報では、メール配信システム「める配くん」の一部サーバへの不正アクセスにより配信先情報の一部が外部に取得されていたことが確認されている。

今回、外部の専門機関と連携して調査を継続する中で、同社が保有していたファイルの一部が実際に外部へ流出していることが新たに確認された。これは7月の事案発生当初「情報漏洩は未確認」としていた状況からの進展であり、調査の進行に伴い被害の実態がより深刻な方向に更新された形となる。日本交通は、個人情報の漏えいが確認された対象者には個別に通知を行うとしており、流出したファイルの内容や件数、原因となった侵入経路の詳細は本稿執筆時点では公表されていない。

本件は2026年半ばに国内の運輸・インフラ事業者を標的とした一連のサイバー攻撃の波の一部と見られており、身代金要求型のランサムウェアグループAiLockが日本交通へのサイバー攻撃を主張したとの報道もあるが、日本交通側からランサムウェア感染の事実は明確に認められていない。
