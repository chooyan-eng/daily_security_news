# npmサプライチェーンワーム、keyv/cacheable経由で数百パッケージに拡散し認証情報を窃取

- **日付**: 2026-08-04
- **出典**: [The Hacker News](https://thehackernews.com/2026/08/keyv-linked-npm-worm-poisons-hundreds.html)
- **トピック**: [npm keyv/cacheable サプライチェーンワーム（2026年8月）](../topics/npm-keyv-cacheable-worm-2026.md)
- **分類**: 新規

## 概要

週間ダウンロード数約1.27億件のnpmパッケージ「keyv」のメンテナーGitHubアカウントが侵害され、資格情報窃取型の自己増殖ワーム（Mini Shai-Hulud亜種）が配布された。ワームは奪取した公開トークンを使ってkeyv/cacheable名前空間を超えて拡散し、2026年8月4日時点で9つの無関係な組織・400以上のパッケージ名（合計月間20億インストール超）に感染が確認されている。

## 詳細

### 攻撃の経緯

攻撃者はkeyv（キー・バリューストレージライブラリ）メンテナーのGitHubアカウントを侵害し、`keyv@6.0.0` を皮切りに悪意あるバージョンを配布した。侵害されたアカウントの権限を使い、同メンテナーが管理するパッケージ群全体に悪意あるリリースを展開した。

### マルウェアの挙動

配布されたパッケージにはpreinstallスクリプトが仕込まれており、インストール時にBunランタイムをダウンロードし、難読化された約728KBのスティーラーを実行する。このスティーラーは以下を標的とする。

- `.npmrc` に保存されたnpm公開トークン
- GitHub CLIトークン
- AWS認証情報
- HashiCorp Vaultトークン
- Kubernetes設定ファイル
- 暗号資産ウォレット関連ファイル

窃取した公開トークンを用いて、ワーム自身をさらに別のパッケージに公開する自己増殖機能を持つ。SafeDepの調査では、9つの無関係な組織（@ornikar、@deliveroo、@onereach、@arv-bedrock、@servicetitan、@qlik を含む）にまたがる400以上のパッケージに、公開からわずか約30分で拡散したことが確認されている。調査時点でSafeDepは1,684個の汚染バージョン・420パッケージ名を、他のセキュリティベンダーは434パッケージ・1,381バージョンを検出しており、合計月間インストール数は20億件を超えるとみられる。

### 影響と対策

CI/CD環境や開発者端末でこれらのパッケージをインストールした場合、上記の認証情報が窃取されている可能性が高い。npm、GitHub、クラウドプロバイダーの認証情報・トークンの即時ローテーション、影響を受けたパッケージのロックファイル固定バージョンの確認、CI実行ログの遡及調査が推奨される。
