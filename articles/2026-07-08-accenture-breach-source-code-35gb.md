# Accenture、ハッカーによる35GB分ソースコード窃取主張を受けて侵害を確認

- **日付**: 2026-07-08
- **出典**: [Help Net Security](https://www.helpnetsecurity.com/2026/07/08/accenture-data-breach-2026/)
- **トピック**: [Accenture データ侵害・ソースコード窃取主張（2026年7月）](../topics/accenture-breach-2026.md)
- **分類**: 新規

## 概要

IT大手 Accenture が、ハッカーフォーラム「PwnForums」上でハンドルネーム「888」を名乗る脅威アクターがソースコード等35GB超のデータ窃取を主張したことを受け、セキュリティインシデントを確認した。窃取が主張されているデータには、ソースコード、RSA/SSHキー、Azure個人アクセストークン、Azureストレージアクセスキー、設定ファイルが含まれる。Accenture は「単発の事案であり、既に原因を是正済み。事業運営・サービス提供への影響はない」とコメントしているが、顧客データへの影響や侵入経路については言及していない。

## 詳細

### 事案の経緯

脅威アクター「888」は、サイバー犯罪フォーラム PwnForums 上に「Accenture の 35GB超のソースコードを保有している」との投稿を行い、データの販売を試みた。主張されている窃取データの内訳は以下の通り：

- ソースコード
- RSA 秘密鍵
- SSH 鍵
- Azure 個人アクセストークン（PAT）
- Azure Storage アクセスキー
- 各種設定ファイル

これらのデータ種別は、クラウドインフラの認証情報・シークレット類が中心であり、侵害が実際に成立していた場合、Accenture が管理する Azure 環境や下流の顧客システムへの二次的な侵害リスクにつながりうる。

### Accenture の公式対応

Accenture は「本件は認識しており、既に原因を是正した。Accenture の事業運営およびサービス提供への影響はない」と声明を発表した。ただし、以下の点については明言を避けている：

- 攻撃者が主張するデータの正確な量・種別
- 顧客データが影響を受けたかどうか
- 攻撃者がどのように初期アクセスを獲得したか

### 過去の関連事案

脅威アクター「888」は2024年6月にも、Accenture の現従業員・元従業員32,826名分のデータを販売しようとしたことがあるが、当時 Accenture は「データセットには氏名と Accenture のメールアドレス3件のみしか含まれていなかった」と反論している。また Accenture は2021年にも LockBit ランサムウェアグループによるデータ窃取被害を受けている。

### クラウドシークレット露出のリスク

本件は、大手コンサルティング・SIer 企業がソースコードだけでなくクラウドの認証キー・トークン類を大量に保持していることのリスクを改めて浮き彫りにしている。Azure PAT やストレージアクセスキーが実際に流出していた場合、攻撃者はそれらを用いて追加のクラウドリソースへ横展開できる可能性があり、単なるコード漏洩以上の実害につながりうる。

### 対策・注意点

- クラウドアクセスキー・PAT のスコープ最小化とローテーション
- ソースコードリポジトリ内のシークレットハードコーディングの排除
- サードパーティ/委託先経由のクラウド認証情報の棚卸し
