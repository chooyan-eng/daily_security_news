# wp2shell：WordPress コア REST API の未認証 RCE 脆弱性（CVE-2026-63030）

- **日付**: 2026-07-18
- **出典**: [The Hacker News](https://thehackernews.com/2026/07/new-wp2shell-wordpress-core-flaw-lets.html)
- **トピック**: [wp2shell WordPress コア 未認証RCE（CVE-2026-63030）](../topics/wp2shell-wordpress-core-rce-2026.md)
- **分類**: 新規

## 概要

WordPress コアに、認証不要でリモートコード実行が可能な重大脆弱性「wp2shell」（CVE-2026-63030）が発見された。REST API のバッチリクエストルート混同と `WP_Query` の SQL インジェクション（CVE-2026-60137）を連鎖させる手口で、影響を受けるバージョンは6.9.0〜6.9.4および7.0.0〜7.0.1。WordPress.org は2026年7月17日に緊急パッチ（7.0.2・6.9.5・6.8.6）を公開した。

## 詳細

### 脆弱性の技術的詳細

wp2shell は2つの脆弱性を連鎖させた攻撃チェーンである。

1. **CVE-2026-60137**：`WP_Query` の `author__not_in` パラメータに存在する SQL インジェクション
2. **CVE-2026-63030**：REST API バッチエンドポイント（`/wp-json/batch/v1`）におけるルート混同の脆弱性

攻撃者はこれらを組み合わせることで、有効なユーザーアカウントやユーザー操作を一切必要とせず、任意のコードをリモートから実行できる。成功した場合、サイト全体とその基盤データが完全に侵害される可能性がある。

### 影響範囲

- 影響バージョン：WordPress コア 6.9.0〜6.9.4、7.0.0〜7.0.1
- プラグイン不要（デフォルトインストールでも攻撃可能）
- 影響を受けるサイト数は数百万規模と報じられている

### 対応・緩和策

WordPress.org は2026年7月17日、7.0.2（および6.9.5・6.8.6へのバックポート）をリリースし、wp2shell の RCE と高深刻度の SQL インジェクションの双方を修正した。パッチ適用が最も効果的な対策とされる一方、即時アップデートが困難な場合の暫定緩和策として、REST API バッチエンドポイント（`/wp-json/batch/v1` および `rest_route=/batch/v1` パラメータ）への匿名アクセスを WAF レベルでブロックすることが推奨されている。

### リスク評価

WordPress は全世界の Web サイトの4割超で利用されているとされ、未パッチのまま放置された場合、大規模な自動化攻撃キャンペーンの標的となるリスクが高い。過去にも WordPress コアやプラグインの RCE 脆弱性は公開後短期間で大量スキャン・悪用が観測されており、早急なパッチ適用が強く推奨される。
