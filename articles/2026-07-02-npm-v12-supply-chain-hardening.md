# npm v12、サプライチェーン対策としてインストールスクリプト等をデフォルト無効化へ

- **日付**: 2026-07-01
- **出典**: [GitHub Changelog](https://github.blog/changelog/2026-06-09-upcoming-breaking-changes-for-npm-v12/) / [Cybernews](https://cybernews.com/security/npm-security-overhaul-adress-supply-chain-attacks/)
- **トピック**: [npm v12 サプライチェーン対策強化（2026年）](../topics/npm-v12-supply-chain-hardening-2026.md)
- **分類**: 新規

## 概要

npmが大型セキュリティ強化版v12を2026年7月にリリース予定。依存パッケージのインストールスクリプト実行、Git依存関係の解決、リモートURL経由の依存取得をすべてデフォルトで無効化し、明示的なオプトインへ転換する。過去最悪規模となったnpmサプライチェーン攻撃の急増を受けた対策。

## 詳細

### 導入される破壊的変更

npm v12では以下3つの破壊的変更が導入される：

1. 依存関係の preinstall/install/postinstall スクリプトの自動実行をデフォルトブロック（`--allow-scripts` 等での明示許可が必要）
2. Git依存関係の解決をデフォルトブロック（`--allow-git`）
3. HTTPS tarball等リモートURL経由の依存取得をデフォルトブロック（`--allow-remote`）

npm 11.16.0以降では警告表示が行われ、CI/CDパイプライン側での事前対応が可能になっている。

### 背景となった攻撃の急増

2025年には約45.5万件の悪性パッケージが公開されるなど、npmエコシステムにおけるサプライチェーン攻撃は過去最悪の水準に達した。直近でも以下のような大型事案が続発している：

- axios（2026年3月31日、週1億ダウンロード規模のパッケージが侵害）
- node-ipc（2026年5月）
- @redhat-cloud-services 名前空間の32パッケージ侵害（2026年6月1日）

### 評価

専門家からは、今回のデフォルト変更は前進ではあるものの「対策としてはまだ不十分」との指摘もある。既存のCI/CDパイプラインでは動作が変わるため、事前の対応（オプトインフラグの設定）が必要になる。
