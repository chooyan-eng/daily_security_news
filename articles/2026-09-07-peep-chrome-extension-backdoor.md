# 偽装ブックマーク拡張機能「PEEP」、ブラウザセッションを窃取しWindows PCをリモートバックドア化

- **日付**: 2026-09-07
- **出典**: [Cyber Security News](https://cybersecuritynews.com/malicious-chrome-extension-2/), [GBHackers](https://gbhackers.com/peep-chrome-extension/), [Cyberpress](https://cyberpress.org/malicious-chrome-extension-backdoor/)
- **トピック**: [Chrome拡張機能悪用の侵害後バックドア「PEEP」（2026年）](../topics/peep-chrome-extension-backdoor-2026.md)
- **分類**: 新規

## 概要

セキュリティ企業SOCRadarは、オープンソースの「RedExt」プロジェクトを流用したChromium拡張機能ベースの侵害後（ポストコンプロマイズ）ツールキット「PEEP」を発見した。正規の「Smart Bookmarks」拡張機能を装い、既に侵害済みのWindows端末のブラウザセッションを窃取した上で、端末自体をリモート操作可能なバックドアに変える。

## 詳細

PEEPは、侵害後の水平展開や永続化に用いられるポストエクスプロイテーションツールであり、初期侵入手段そのものではない点が特徴である。SOCRadarのアナリストは、「Smart Bookmarks」バージョン1.3.0を名乗る主要ビルドに加え、関連するテスト用バリアント、さらには攻撃者側の開発リポジトリが公開状態で露出しているのを発見し、これらを分析することで攻撃基盤の詳細を特定した。

この拡張機能はインストール時に、タブ、Cookie、閲覧履歴、ブックマーク、ダウンロード履歴、ブラウザ設定、スクリプト実行、そしてすべてのWebサイトへのアクセスという広範な権限を要求する。実行されると、対象端末上でアクティブなログインセッション（認証Cookie等）を窃取できるほか、ブラウザ拡張機能から連携するWindows向けコンパニオンプログラムを呼び出すことで、シェルコマンドの実行、ファイル操作、実行中プロセス・サービスの列挙といった、現在ログイン中のユーザー権限でのホスト操作が可能になる。つまりブラウザ拡張機能を足掛かりに、侵害済みのブラウザを常時操作可能な遠隔バックドアへと変換する仕組みである。

SOCRadarが確認した攻撃者側サーバーのステータス情報には、34件のエージェントエントリ、10件のアクティブセッション、507件のデータレコードが記録されていたが、これらにはテスト用の識別子も含まれている可能性があり、実際の感染端末数を正確に示すものではないとされる。

PEEPの発見は、正規のChromeウェブストアの審査を経た拡張機能であっても、侵害後の攻撃ツールとして悪用され得ることを改めて示している。企業のセキュリティチームには、エンドポイント上で不審な拡張機能のインストールや、拡張機能からのネイティブメッセージング経由の外部プログラム呼び出しを監視することが推奨される。個人ユーザーに対しても、身に覚えのないブックマーク管理系拡張機能や、過度に広範な権限を要求する拡張機能については、インストール状況を定期的に見直すことが望ましい。
