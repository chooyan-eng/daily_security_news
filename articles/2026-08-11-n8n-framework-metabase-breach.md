# n8n・Framework 等がMetabaseゼロデイ経由で顧客情報漏洩を確認

- **日付**: 2026-08-11
- **出典**: [n8n Blog](https://blog.n8n.io/metabase-security-incident-update/)
- **トピック**: [Metabase SQLインジェクションゼロデイ（CVSS 10.0、2026年8月）](../topics/metabase-sqli-zeroday-2026.md)
- **分類**: 続報

## 概要

ワークフロー自動化プラットフォーム n8n は2026年8月8日、Metabase の未認証SQLiゼロデイ脆弱性を悪用され、136件の顧客レコード（氏名・メールアドレス、うち5件はbcryptハッシュ化パスワードを含む）が第三者に窃取されたと発表した。PCメーカー Framework も同様の手口で顧客連絡先情報が窃取された。

## 詳細

### n8n のインシデント

n8n は、自社の Metabase 環境において第三者が不正にデータへアクセス・クエリを実行したことを確認したと発表した。窃取されたのは、セルフホスト版・n8n Cloud版双方のユーザーに関する氏名とメールアドレスを含む136件のレコードで、うち5件には n8n Cloud アカウントの bcrypt ハッシュ化パスワードが含まれていた（セルフホスト版のパスワードは n8n と共有されない仕様のため対象外）。n8n は影響を受けた可能性のある認証情報のローテーション、影響を受けたユーザーへの是正措置、データ保護当局への通知を実施済みとしている。

### Framework のインシデント

PCメーカー Framework も同一の Metabase ゼロデイを悪用され、顧客の氏名・ログインIPアドレス・住所・電話番号・メールアドレスにアクセスされたことを顧客に通知した。決済情報や認証情報は含まれていないとされる。

### 広範な影響

本件は Metabase の未認証SQLiゼロデイ脆弱性を悪用した一連の攻撃キャンペーンの一部であり、Kilo Code など他の組織も同様の被害を受けたと報じられている。脆弱性自体の詳細は [Metabase 認証不要SQLインジェクション・ゼロデイ（CVSS 10.0）が実悪用、管理者権限奪取が可能に](../articles/2026-08-11-metabase-sqli-zero-day.md) を参照。Metabase を自組織で運用する企業は、脆弱性修正済みバージョンへの早急なアップデートが求められる。
