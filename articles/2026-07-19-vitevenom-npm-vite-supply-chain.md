# 「ViteVenom」— Vite エコシステムを狙う悪意ある npm パッケージ7件、ブロックチェーン C2 で RAT を配布

- **日付**: 2026-07-19
- **出典**: [The Hacker News](https://thehackernews.com/2026/07/seven-malicious-vite-npm-packages-use.html)
- **トピック**: [ViteVenom：Vite npm サプライチェーン攻撃（2026年）](../topics/vitevenom-npm-vite-supply-chain-2026.md)
- **分類**: 新規

## 概要

フロントエンドビルドツール Vite のエコシステムを標的とした、7件の悪意ある npm パッケージ群「ViteVenom」（Checkmarx 命名）が発見された。既存の攻撃キャンペーン「ChainVeil」の拡張とみられ、Tron・Aptos・Binance Smart Chain にまたがる「4層」のブロックチェーンベース C2 インフラを用いてリモートアクセス型トロイの木馬（RAT）を配布する。パッケージは `@vitejs/*` 名前空間を模したスコープ付きパッケージ名で正規性を装っている。

## 詳細

### キャンペーンの背景

ViteVenom は、Checkmarx の研究者によって命名された npm サプライチェーン攻撃キャンペーンであり、既知の攻撃キャンペーン「ChainVeil」の拡張・発展形と位置づけられている。ChainVeil はこれまで、Tron・Aptos・Binance Smart Chain の3つのブロックチェーンにまたがる「前例のない」4層構造のブロックチェーンベース C2 インフラを用いて RAT を配布してきたことで知られる。

### 攻撃対象と手口

ChainVeil のこれまでの手口（無関係なパッケージ名を騙るタイポスクワッティング）とは異なり、ViteVenom は `@vitejs/*` という Vite 公式のスコープ付き名前空間を模倣したパッケージ名を採用しており、開発者に対してより高い正規性の錯覚を与える設計になっている。これによりフロントエンド開発者が Vite の公式パッケージと誤認してインストールするリスクが高まる。

### RAT の機能

配布される RAT は以下の機能を備える：
- リバースシェルの確立
- 認証情報の窃取（クレデンシャルハーベスティング）
- ファイルの窃取・外部への持ち出し
- 永続的なバックドアの埋め込み

### 攻撃者・タイムライン

活動は脅威アクター「SuccessKey」に帰属するとされる。ViteVenom に関連する暗号資産ウォレットは2026年2月27日の時点で既に活動が確認されており、実際に悪意あるパッケージが npm に公開されたのは2026年6月29日から7月3日にかけてであった。

### 推奨対策

- `@vitejs/*` 名前空間のパッケージを導入する際は、公式リポジトリ・公式メンテナーによる公開であることを厳密に確認する
- package-lock.json 等でのパッケージハッシュ検証、依存関係の定期監査を実施する
- CI/CD 環境における予期しないブロックチェーンネットワークへの通信（Tron/Aptos/BSC 関連 RPC 等）を監視する
- npm の provenance（来歴）機能を活用し、パッケージの公開元を検証する
