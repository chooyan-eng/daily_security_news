# スイス連邦IT局、SharePoint サーバーへの不正アクセスで約200アカウントの認証情報が流出

- **日付**: 2026-08-07
- **出典**: [Help Net Security](https://www.helpnetsecurity.com/2026/08/07/swiss-government-microsoft-sharepoint-vulnerabilities/)
- **トピック**: [Storm-2603 SharePoint 脆弱性悪用・ランサムウェアキャンペーン（2026年）](../topics/storm-2603-sharepoint-ransomware-2026.md)
- **分類**: 関連

## 概要

スイス連邦情報技術通信局（BIT）は、自組織が運用する Microsoft SharePoint サーバーに対する不正アクセスを2026年7月28日に検知し、調査の結果、約200のユーザー・技術アカウントの認証情報が窃取されたことを公表した。攻撃者は2026年7月の Patch Tuesday で修正された SharePoint の脆弱性（CVE-2026-56164 または CVE-2026-50522 のいずれかとみられる）を悪用したと推定されている。現時点で認証情報以外のデータ持ち出しの証拠は確認されていない。

## 詳細

### インシデントのタイムライン

- 7月28日（火）: BIT が SharePoint 環境での異常な挙動を検知
- 7月31日: セキュリティ専門チームが複数アカウントの認証情報侵害を確認
- 対応: 該当 SharePoint システムへのインターネットアクセスを即座に遮断し、必要なセキュリティ修正を適用
- 8月上旬: スイス連邦サイバーセキュリティ局および Microsoft の支援を受けて調査継続中、8月7日時点で報道機関に詳細が共有された

### 悪用された脆弱性（推定）

BIT は、2026年7月中旬に Microsoft が開示し、同月の Patch Tuesday で修正された SharePoint の脆弱性が侵入経路になった可能性が高いとみている。具体的には、積極的に悪用されている権限昇格の脆弱性 CVE-2026-56164、またはリモートコード実行の脆弱性 CVE-2026-50522 のいずれかが使用された可能性がある。

### 影響範囲

現時点で判明しているのは約200件のユーザー・技術アカウントのログイン情報の侵害であり、それを超えるデータの持ち出しは確認されていない。ただし正確な影響アカウント数はまだ確定していない。

### 既存の SharePoint 悪用キャンペーンとの関連

2026年6月には、脅威アクター Storm-2603 が未修正のオンプレミス SharePoint サーバーを標的に、独自ツールセット「Project AK47」（バックドア・ランサムウェア）を展開するキャンペーンが確認されている（本件とは悪用 CVE が異なる）。今回のスイス政府事案は同一キャンペーンとは断定できないものの、SharePoint（特にオンプレミス版）が年間を通じて繰り返し標的にされている状況を示す一例として、関連情報として記録する。

### 対策

- 2026年7月 Patch Tuesday（SharePoint 関連修正）の適用状況確認
- SharePoint 管理者・サービスアカウントのパスワードローテーション
- 外部公開している SharePoint オンプレミス環境の棚卸しとインターネット直接公開の見直し
