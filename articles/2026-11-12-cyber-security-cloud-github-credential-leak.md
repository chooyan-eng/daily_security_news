# サイバーセキュリティクラウド、従業員のGitHub認証情報1件が流出し不審アクセス 顧客情報漏えいのおそれ

- **日付**: 2026-11-12
- **出典**: [テレビ朝日系（ANN）／Yahoo!ニュース](https://news.yahoo.co.jp/articles/1602bc8c65ca6c67ca17f3a81c8febee7611446a)
- **トピック**: [サイバーセキュリティクラウド GitHub認証情報流出事案（2026年11月）](../topics/cyber-security-cloud-github-credential-leak-2026.md)
- **分類**: 新規

## 概要

WAF等のクラウド型セキュリティサービスを提供するサイバーセキュリティクラウドは11月12日、従業員が業務で使用していたGitHubの認証情報1件が外部に流出し、これを用いたとみられる不審アクセスを確認したと発表した。一部顧客の企業名・氏名・メールアドレスや通信関連情報が漏えいしたおそれがある。

## 詳細

### 概要

- 外部機関からの情報提供を受けて判明。不審アクセスの確認日は11月5日とされる。
- 流出したのは従業員が業務で使用していた**GitHub認証情報1件**。これを利用したとみられる不審なアクセスがあった。
- 一部顧客の企業名、氏名、メールアドレス、通信関連情報について、第三者による閲覧・取得の可能性を否定できないとしている。
- サービス本体への不正アクセス・不正操作、二次被害、セキュリティ機能への影響は現時点で確認されておらず、サービス提供は継続。
- 流出した認証情報を無効化し、開発端末を隔離。個人情報保護委員会など関係機関へ報告済みで、対象顧客には順次案内する。

### 技術的な補足

- 「開発端末を隔離」という対応から、開発者端末のマルウェア感染（インフォスティーラー等）によりトークンが窃取された可能性が考えられるが、公式には原因は明示されていない（推測）。
- GitHub の認証情報（PAT、OAuthトークン、SSH鍵など）が漏れると、アクセス可能なリポジトリの**ソースコード、コミット履歴、Issue／PR、CI設定**が取得されうる。顧客情報が「リポジトリ内に存在した」ことが漏えいのおそれにつながっているとみられ、テストデータ、ログ、設定ファイル、サポート対応用スクリプト等に実データや通信ログが混入していた可能性がある。
- 二次リスクとして、リポジトリや CI シークレットに含まれるクラウド／APIキーの横展開がある。同種の事案では、リポジトリ内シークレットの全ローテーションと監査ログ（audit log、Git clone イベント）の確認が必須となる。
- 対策の要点: fine-grained PAT と短い有効期限、組織での SSO 強制と IP 許可リスト、シークレットスキャンと push protection、リポジトリへの顧客データ持ち込み禁止、開発端末の EDR。
- WAF ベンダーの事案であるため、利用企業は自社のWAF設定情報や通信ログが対象に含まれるかを同社の個別案内で確認したい。
