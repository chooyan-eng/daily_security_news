# jscrambler npmパッケージが侵害され、開発者端末を狙うRust製インフォスティーラーが混入

- **日付**: 2026-07-14
- **出典**: [The Hacker News](https://thehackernews.com/2026/07/compromised-jscrambler-8140-npm-release.html)
- **トピック**: [jscrambler npm サプライチェーン攻撃 - Rust製インフォスティーラー混入（2026年7月）](../topics/jscrambler-npm-supply-chain-2026.md)
- **分類**: 新規

## 概要

JavaScript難読化ツールを提供するセキュリティベンダー Jscrambler の npm パッケージが2026年7月11日に侵害され、正規のメンテナーアカウントから悪意あるバージョンが公開された。インストール時にRust製のクロスプラットフォーム型インフォスティーラーが実行され、クラウド認証情報や暗号資産ウォレット等の窃取が試みられた。

## 詳細

### 侵害の内容

Jscrambler社が提供するnpmパッケージ「jscrambler」および関連プラグイン群のバージョン8.14.0、8.16.0、8.17.0、8.18.0、8.20.0が、2026年7月11日の約3時間の間に連続して悪意あるバージョンとしてnpmレジストリに公開された。これらは正規のメンテナーアカウントから通常のリリースフローを経ずに直接pushされており、npmアカウントまたはビルドパイプラインの侵害が原因とみられている。

### ペイロードの内容

悪性バージョンにはpreinstallフックが仕込まれており、npm install実行時にWindows・macOS・Linux向けにそれぞれビルドされたネイティブバイナリ（Rust製インフォスティーラー）がドロップ・実行される。このマルウェアは開発者端末上の以下の情報を標的とする。

- AWS、Azure、Google Cloudのクラウド認証情報（CIランナーが使用するメタデータエンドポイント情報を含む）
- MetaMask、Phantom、Exodus等の暗号資産ウォレットとシードフレーズ
- Bitwardenパスワードマネージャーのボルトデータ

窃取された情報はTLS経由で攻撃者の外部サーバーへ送信される。

### 影響範囲と対応

セキュリティ企業Socketの分析により、jscrambler、jscrambler-webpack-plugin、gulp-jscrambler、grunt-jscrambler、jscrambler-metro-pluginを含む複数の関連パッケージが同一の攻撃者によって侵害されたことが判明。悪性バージョンの合計ダウンロード数は削除前で1,479件。該当バージョンは全て非推奨化され、npmの依存解決からは除外済み。安全なバージョンとしてjscrambler 8.22.0等が提供されている。

### 技術的補足

セキュリティベンダー自身が提供するツールが侵害されるケースは、開発者が「信頼済みツール」として警戒を緩めやすいという点で特に危険性が高い。今回の攻撃はビルド・難読化ツールという開発パイプラインの根幹に位置するパッケージを狙っており、CI/CD環境のクラウド認証情報やシークレットへの到達を企図した設計になっている。影響を受けた開発者は、認証情報・APIキー・ウォレットのローテーションを速やかに行う必要がある。
