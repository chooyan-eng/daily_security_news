# 「CosmosEscape」— Azure Cosmos DB のほぼ全データベースを乗っ取り可能だった重大脆弱性、Wiz が詳細公開

- **日付**: 2026-07-30
- **出典**: [The Hacker News](https://thehackernews.com/2026/07/azure-cosmos-db-flaw-exposed-platform.html)
- **トピック**: [CosmosEscape：Azure Cosmos DB プラットフォーム全体の乗っ取り脆弱性](../topics/cosmosescape-azure-cosmos-db-2026.md)
- **分類**: 新規

## 概要

セキュリティ企業Wizは、Microsoft Azure Cosmos DBのGremlin APIに存在した重大な脆弱性「CosmosEscape」の詳細を2026年7月30日前後に公開した。悪用された場合、プラットフォーム上のほぼ全てのCosmos DBデータベース（Microsoft自社の内部システムを含む）に対する読み書き権限を持つマスターキーを取得できるおそれがあった。Microsoftは2025年11月の報告後、応急処置とその後の恒久的アーキテクチャ修正を完了している。

## 詳細

### 脆弱性の技術的背景

CosmosEscapeは、Azure Cosmos DBが利用するカスタムGremlinクエリエンジンの脆弱性に起因する。Wizの研究者はGremlinクエリのテスト中に.NET例外が発生することに気づき、同サービスがグラフクエリを実行可能な.NETコードへ変換していることを突き止めた。さらなる分析の結果、このエンジンのセキュリティ制限が.NETのリフレクション技術の悪用を防ぐには不十分であることが判明した。

### 影響の深刻さ

この脆弱性を突くことで、攻撃者はWizが「Cosmos Master Key」と呼ぶプラットフォーム全体の秘密鍵を取得できた可能性がある。これは任意のCosmos DBアカウントの主キーをオンデマンドで取得し、完全な読み書きアクセス権を得る「テイクオーバー」を可能にするものであり、悪用が成功すればクロステナント攻撃として数百万規模の顧客ワークロードおよびMicrosoft自社の内部インフラに影響が及んだ可能性がある。

### 発見と対応のタイムライン

WizはMicrosoftに2025年11月に脆弱性を報告。Microsoftは2日以内に攻撃経路を遮断する応急パッチを展開し、その後2026年7月に全リージョンへの恒久的なアーキテクチャ修正の展開を完了した。Microsoftは脆弱性を完全に修正したこと、および顧客への影響の証跡は見つかっていないことを表明している。

### 意義

クラウドデータベースサービスにおけるマルチテナント分離の設計不備が、単一の脆弱性でプラットフォーム全体に波及するリスクを改めて示す事例として、クラウドセキュリティ業界で注目されている。
