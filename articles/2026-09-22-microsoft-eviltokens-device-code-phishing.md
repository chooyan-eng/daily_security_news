# Microsoft、デバイスコードフィッシング「EvilTokens」の内部構造を詳細分析したレポートを公開

- **日付**: 2026-09-22
- **出典**: [Microsoft Security Blog](https://www.microsoft.com/en-us/security/blog/2026/09/22/unmasking-eviltokens-getting-to-the-root-of-device-code-phishing/)
- **トピック**: [デバイスコードフィッシング / AiTM セッショントークン窃取（2026年）](../topics/device-code-phishing-aitm-2026.md)
- **分類**: 続報

## 概要

Microsoftは、2026年2月の登場以来もっとも広く利用されたAI搭載型フィッシング・アズ・ア・サービス（PhaaS）基盤「EvilTokens」の内部構造を詳細に分析したレポートを公開した。同基盤は全世界1万組織超・1万2000件超の受信箱を侵害してきたとされ、AIによるフィッシング文面の自動生成や、侵害済み受信箱の自動分析機能などを備えていたことが明らかにされた。

## 詳細

Microsoftのセキュリティチームは2026年9月22日、デバイスコードフィッシング・AiTM（Adversary-in-the-Middle）攻撃のインフラとして猛威を振るってきたフィッシング・アズ・ア・サービス（PhaaS）プラットフォーム「EvilTokens」について、その内部構造にまで踏み込んだ詳細分析レポート「Unmasking EvilTokens: Getting to the root of device code phishing」を公開した。

EvilTokensは2026年2月に初めて確認されて以来、犯罪者コミュニティにおいて最も広く利用されるPhaaS基盤のひとつへと急速に成長した。単なるフィッシングキットの提供にとどまらず、AI機能を組み込むことでフィッシング文面（ルアー）のカスタマイズや、侵害済みメール受信箱の内容分析を自動化し、ビジネスメール詐欺（BEC）キャンペーンを高度に効率化していた点が特徴とされる。これまでの追跡調査により、同基盤を用いたキャンペーンは全世界1万組織を超える環境で、1万2000件を超えるメール受信箱を侵害してきたことが判明している。

技術的な観点では、EvilTokensはOAuth 2.0のデバイス認証フロー（Device Authorization Grant）を悪用し、ユーザーのパスワードやMFA（多要素認証）を経由せずに、認証済みのセッショントークンを直接窃取する手口を用いる。2026年4月にMicrosoftが追跡した関連キャンペーンでは、自動化基盤を用いて大量の短命な「ポーリングノード」を動的に生成し、デバイスコードの生成から侵害後の活動までを一気通貫で処理する複雑なバックエンドロジックを展開することで、シグネチャベースの検知を回避していたことが報告されている。

今回公開されたレポートでは、こうしたインフラの構成要素や運用体制がさらに詳細に解説されており、EvilTokensの「ゴーストフィッシング」と呼ばれる手法（ブラウザ内でAES-GCM暗号化されたフィッシングページをその場で復号して表示することで、静的なURLスキャンや従来型のコンテンツフィルタリングを回避する仕組み）についても改めて掘り下げられている。デバイスコードフィッシングは2026年6月時点で検出件数が前年比37倍に急増し、パスワード強化やTOTP／SMSによるMFA、さらにはパスキーによる認証強化策でも効果的に防げない攻撃手法として、複数の主要AiTMプラットフォームに採用されるまでにコモディティ化が進んでいる。

Microsoftは今回のレポート公開を通じて、組織に対しデバイスコードフローの利用制限や条件付きアクセスポリシーの厳格化、異常なサインインパターンの監視強化など、より実効性の高い防御策の検討を呼びかけている。
