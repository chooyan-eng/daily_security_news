# AsyncAPI サプライチェーン攻撃：GitHub Actions の「pwn request」脆弱性悪用で Miasma 系マルウェアを拡散

- **日付**: 2026-07-19
- **出典**: [Microsoft Security Blog](https://www.microsoft.com/en-us/security/blog/2026/07/15/unpacking-asyncapi-npm-supply-chain-compromise-import-time-payload-delivery/)
- **トピック**: [Red Hat npmサプライチェーン攻撃（Miasma）](../topics/redhat-npm-supply-chain-miasma.md)
- **分類**: 続報

## 概要

2026年7月14日、AsyncAPI Generator リポジトリの GitHub Actions ワークフローの設定不備（「pwn request」脆弱性）を突いた攻撃者が、高権限の Personal Access Token を窃取し、`@asyncapi` 名前空間の npm パッケージ4件に悪意あるコードを注入した。配布されたペイロードは、2026年6月に発見された Miasma RAT の系統に連なるマルウェアローダーであり、週間300万ダウンロードを超える人気パッケージ群が汚染された。

## 詳細

### 攻撃の発端

2026年7月14日、攻撃者は AsyncAPI Generator リポジトリに対して37件のプルリクエストを送信した。このうち1件が、GitHub Actions の `pull_request_target` トリガーを利用したワークフローの設定不備を悪用するものだった。`pull_request_target` はベースリポジトリのコンテキスト（＝シークレットへのフルアクセス権）で実行される一方、プルリクエスト由来の攻撃者制御下のコードをチェックアウトして実行してしまう構成になっていたため、高権限の Personal Access Token が攻撃者の手に渡った。この種の脆弱性クラスは「pwn request」と呼ばれる。

### 汚染されたパッケージ

窃取したトークンを用いて、攻撃者は `@asyncapi` 名前空間のパッケージ4種・5バージョンを約90分の間に連続して公開し、いずれにも同一の悪意あるローダーが注入されていた。これらのパッケージは合計で週間300万ダウンロードを超える利用実績を持つ。

### ペイロードと Miasma との関連

配布されたマルウェアは、macOS・Linux・Windows の各環境に対応する多段型ローダーであり、最終的に高度なボットネットフレームワーク「Miasma」を展開する。Microsoft のセキュリティチームの分析では、このペイロードは2026年6月に Wiz Research が報告した Red Hat npm パッケージを標的としたサプライチェーン攻撃「Miasma」の系統に連なるマルウェアであることが確認されている。

### 既知だった脆弱性が放置されていた経緯

この GitHub Actions の脆弱性クラスは事前に把握されていた。2026年4月29日にはコントリビューターが概念実証（PoC）ペイロードを添えて問題を指摘するプルリクエストを提出し、5月17日にはシークレットアクセスと信頼できないコードの実行を分離するようワークフローを2つのジョブに分割する修正案が提示されていた。しかし、この修正は攻撃が発生した7月14日の時点でも未マージのまま放置されていた（提案から58日間）。

### 推奨対策

- GitHub Actions において `pull_request_target` を使用するワークフローでは、シークレットへのアクセスと信頼できないコードの実行を必ず別ジョブに分離する
- 依存関係に `@asyncapi` 名前空間のパッケージが含まれる場合、汚染されたバージョンを使用していないか確認し、影響を受けたバージョンからの更新・ロールバックを行う
- 既知のセキュリティ修正提案（PR）が長期間未マージのまま放置されていないか、リポジトリの棚卸しを行う
- Miasma 系マルウェアの IOC（侵害指標）に基づき、CI/CD 環境および開発者端末のスキャンを実施する
