# フィリピンの配車アプリJoyRideがサイバー攻撃を認める──攻撃者は顧客2,050万件・ドライバー42万件の窃取を主張、通勤者団体が全容開示を要求

- **日付**: 2026-11-23
- **出典**: [BusinessMirror](https://businessmirror.com.ph/2026/11/23/commuter-group-to-joyride-disclose-full-scope-of-data-breach-notify-every-affected-customer-rider/)
- **トピック**: [JoyRide アプリ データ侵害（2026年11月）](../topics/joyride-app-breach-2026.md)
- **分類**: 新規

## 概要

フィリピンのバイクタクシー・配車アプリJoyRideは11月19日、サイバー攻撃を受け一部データが侵害された可能性があると認めた。「LelouchX 1337」を名乗る攻撃者は約504GB、顧客プロフィール2,050万件超とドライバー登録42万件超の窃取を主張している。11月23日には通勤者団体が全容の開示と全対象者への通知を求めた。

## 詳細

JoyRideは11月19日の声明でサイバーセキュリティインシデントを確認し、調査中であるとした。影響人数や流出したデータの種類は公表しておらず、サービスは引き続き安全に利用できると説明、利用者にはOTP（ワンタイムパスワード）を他人に教えないこと、不審なSMSに応じないことを呼びかけている（[出典: Philstar](https://www.philstar.com/business/2026/11/20/2571254/joyride-confirms-app-data-breach)）。

攻撃者側の主張（JoyRideは未確認）:

- 攻撃者名: LelouchX 1337
- 規模: 約504GB、顧客プロフィール2,050万件超、ドライバー登録記録42万件超
- 侵入先: Firebase の Firestore および Cloud Storage のバックエンドにアクセスしたと報じられている

フィリピンのセキュリティ啓発団体Deep Web Konekは、ドライバー登録情報と顧客プロフィールが露出したとして、詐欺・なりすまし・フィッシングのリスクを高いと評価している。11月23日には通勤者団体Lawyers for Commuters Safety and Protectionが、侵害の全容開示と影響を受けた全顧客・ライダーへの通知をJoyRideに求め、国家捜査局（NBI）にも対応を要請した。国家プライバシー委員会（NPC）が調査を開始したとの報道は確認できていない。

技術的な補足: Firestore／Cloud Storageが侵入先とされている点は、モバイルアプリ開発者にとって重要である。Firebaseを使うアプリでは、(1) セキュリティルールが認証済みユーザーなら誰でも全コレクションを読める状態（`allow read: if request.auth != null`）になっている、(2) アプリのバイナリやリポジトリにサービスアカウント鍵が含まれている、(3) Cloud Storageバケットが公開または一覧可能、といった設定不備が大量流出の典型的な原因となる。本件の原因は未公表だが、アプリに埋め込まれたFirebase設定値（APIキー、プロジェクトID）は公開情報である前提で、ルール側で所有者単位のアクセス制御を行い、App Checkを有効化し、ドライバーの本人確認書類のような機微ファイルは署名付きURL経由でのみ配信する構成が望ましい。
