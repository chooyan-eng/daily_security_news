# AI生成のブラウザ内蔵型ランサムウェアがChromium File System Access APIを悪用 — Windows・Android等で動作確認

- **日付**: 2026-07-08
- **出典**: [The Hacker News](https://thehackernews.com/2026/07/ai-generated-browser-ransomware-abuses.html)
- **トピック**: [AI生成ブラウザ内蔵型ランサムウェア「InfernoGrabber」（Chromium File System Access API悪用）](../topics/ai-browser-ransomware-chromium-api-2026.md)
- **分類**: 新規

## 概要

セキュリティ研究者が、DeepSeek を用いて生成されたマルウェアサンプルが、これまで「理論上は可能だが非現実的」とされてきたブラウザ完結型ランサムウェアの攻撃手法を実際に動作する形で実現していたことを発見した。Chromium系ブラウザに実装されている File System Access API を悪用し、ネイティブペイロードのインストールやブラウザの脆弱性悪用、root権限なしに、ユーザーが許可したフォルダ内のファイルを暗号化・上書きする。Windows・macOS・Linux・Android・Edgeにまたがって動作が確認された。

## 詳細

### 攻撃手法

1. フィッシングのおとり（偽の Discord アバターAIアップスケーラー等）でユーザーを誘導
2. Webページ上でユーザーにファイルシステムへのフォルダアクセス許可を求め、承諾させる
3. File System Access API を用いて選択されたフォルダ内のローカルファイルを列挙
4. ファイル内容を読み取り外部へ窃取
5. ファイルを暗号化した上で上書き
6. 身代金要求メッセージを表示

この一連の攻撃は、ネイティブペイロードのインストール、ブラウザの脆弱性悪用、root/管理者権限の取得のいずれも必要とせず、Chromium系ブラウザに標準実装された正規APIの機能範囲内で完結する。

### マルウェアサンプルの詳細

発見されたサンプルは "deepseek_python_20260125_da0631.py" という名称の Python Flask アプリケーションで、2026年1月25日に VirusTotal へアップロードされていた。Google傘下のマルウェアスキャンサービスはこれを「完全に機能する情報窃取・ランサムウェアツールキット」と評価。マルウェア作者自身はこれを「InfernoGrabber v9.0」と命名している。

このアプリケーションは、偽の Discord アバターAIアップスケーラーを装う悪意あるWebサーバーとして動作し、裏側で以下を実行する：

- Discord トークンの窃取
- クレジットカード番号・暗号資産シードフレーズの収集
- キーストロークのロギング
- 無断でのWebカメラ・マイクへのアクセス

### 影響プラットフォーム

File System Access API は Chromium ベースのブラウザに実装されているため、Windows・macOS・Linux・Android、および Windows版 Microsoft Edge を含む幅広いデスクトップ・Android利用者が理論上の影響対象となる。ただし、現時点でこのブラウザ完結型ランサムウェア手法が実際の攻撃で悪用された証拠は確認されていない。

### 意義

本件は、フロンティアAIモデルが独力で「理論的リスク」と「実用的な攻撃チェーン」の間のギャップを埋めた初の事例として注目されている。ブラウザのサンドボックス制限により実現不可能と考えられてきた攻撃パターンを、AIが試行錯誤なく組み上げてしまった点が、防御側の想定を覆す新たなリスクとして指摘されている。

### 対策

- 見知らぬWebサイトからのファイルシステムアクセス許可要求には応じない
- ブラウザのファイルシステムアクセス許可の付与状況を定期的に確認・取り消す
- 重要ファイルの多重バックアップ（オフライン含む）を維持
