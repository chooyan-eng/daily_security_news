# WordPress 予約プラグイン「TrueBooker」に重大な認可バイパス – 未認証で管理者パスワードを変更可能

- **日付**: 2026-08-07
- **出典**: [Patchstack](https://patchstack.com/database/wordpress/plugin/truebooker-appointment-booking/vulnerability/wordpress-truebooker-plugin-1-1-9-broken-access-control-vulnerability?_s_id=cve)
- **トピック**: [TrueBooker WordPress プラグイン認可バイパス（2026年8月）](../topics/truebooker-wordpress-plugin-2026.md)
- **分類**: 新規

## 概要

WordPress の予約・スケジューリングプラグイン「TrueBooker – Appointment Booking and Scheduler System」の 1.2.3 以下（パスワードリセット関連は 1.2.4 未満）に、認可バイパスの重大な脆弱性が発見された。フロントエンドのアカウントパスワードリセット機能がアカウント所有権を検証しないため、未認証の攻撃者が管理者を含む任意のユーザーアカウントのパスワードを設定し、サイトを完全に乗っ取ることが可能。CVE-2026-14364・CVE-2026-14365・CVE-2026-14545 として採番されている。

## 詳細

### 脆弱性の技術的詳細

TrueBooker のフロントエンドアカウントハンドラーは、パスワードリセットリクエストを処理する際にリクエスト対象のアカウントが本当にリクエスト送信者本人のものかを検証していない。この不備（CWE-269: 不適切な権限管理／認可バイパス）により、攻撃者はユーザー名またはメールアドレスを指定するだけで、認証情報なしに任意アカウント（管理者含む）のパスワードを任意の値に上書きできる。

**CVE 一覧**
- CVE-2026-14365: パスワードリセットに関連する認可バイパス
- CVE-2026-14364: 不適切なパスワードリセット検証によるアカウント乗っ取り
- CVE-2026-14545: パスワードリセット機能における不適切な権限管理

### 影響

管理者アカウントを乗っ取られた場合、攻撃者はプラグイン・テーマの編集機能を通じて任意のコードを実行でき、サイト全体の完全な制御（Web シェル設置、マルウェア埋め込み、他サイトへの踏み台化等）に発展しうる。WordPress は世界の Web サイトの4割超で使用されており、予約系プラグインは中小企業サイトでの導入率が高い。

### 対策

- TrueBooker を修正版（1.2.4 以降）へ直ちにアップデート
- 該当プラグインを使用しているサイトの管理者パスワード変更履歴・不審なログインを確認
- WAF によるパスワードリセットエンドポイントへの異常リクエストの検知
