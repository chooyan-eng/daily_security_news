# 「TheHatman」を名乗る攻撃者、侵害した Azure/Entra ID テナントから複数企業の従業員名簿を闇市場で販売

- **日付**: 2026-08-18
- **出典**: [Cyber Press](https://cyberpress.org/hackers-use-compromised-azure-credentials/)
- **トピック**: [TheHatman による Azure/Entra ID 認証情報侵害キャンペーン（2026年）](../topics/azure-entra-credential-theft-thehatman-2026.md)
- **分類**: 新規

## 概要

地下フォーラムで「TheHatman」を名乗る攻撃者が、侵害したMicrosoft AzureおよびEntra IDテナントから窃取した複数企業の従業員名簿データを販売していることが確認された。窃取した企業の正規認証情報を悪用してクラウドディレクトリサービスにアクセスしたとみられ、技術サービス・ホスピタリティ・通信・小売・物流分野の少なくとも9社のFortune 500クラス企業のデータが対象に含まれるとされる。

## 詳細

### キャンペーンの概要

2026年8月17日、地下フォーラム上で大規模なAzureデータ窃取に関する情報が拡散した。「TheHatman」を名乗る脅威アクターが、複数の大企業から取得したとみられる社内従業員ディレクトリ情報の販売リストを掲載している。

### 手口

攻撃者は、窃取済みの正規企業認証情報を用いて、侵害されたMicrosoft AzureおよびEntra ID（旧Azure Active Directory）テナントにアクセスし、内部の従業員ディレクトリデータを外部に持ち出したとみられる。フィッシングやインフォスティーラーマルウェアによる認証情報窃取が侵入起点になった可能性が高い。

### 影響範囲

販売リストには、技術サービス、ホスピタリティ、通信、小売、物流の各分野にまたがる、少なくとも9社のFortune 500クラスの多国籍企業のデータが含まれているとされる。クラウドディレクトリサービスに依存する現代の企業ITにとって、アイデンティティ基盤そのものが侵害された場合の深刻な事業リスクを示す事例といえる。

### リスクと対応

従業員ディレクトリ情報（氏名、役職、連絡先、組織構造など）の漏洩は、それ自体が機密性の高いデータであると同時に、標的型フィッシングやビジネスメール詐欺（BEC）、なりすましによる二次攻撃の土台となる。企業は、クラウドディレクトリへのアクセスに多要素認証を徹底し、条件付きアクセスポリシーや異常なサインイン活動の監視を強化することが求められる。
