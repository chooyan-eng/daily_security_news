# ViteVenom：Vite エコシステムを標的としたブロックチェーン C2 npm サプライチェーン攻撃

- **日付**: 2026-07-18
- **出典**: [The Hacker News](https://thehackernews.com/2026/07/seven-malicious-vite-npm-packages-use.html)
- **トピック**: [ViteVenom npm サプライチェーン攻撃（2026年7月）](../topics/vitevenom-npm-supply-chain-2026.md)
- **分類**: 新規

## 概要

セキュリティ企業 Checkmarx が、フロントエンドビルドツール Vite のエコシステムを標的にした悪意ある npm パッケージ群「ViteVenom」を発見した。`@vitejs/*` の命名を模倣した7個のパッケージが、Tron・Aptos・Binance Smart Chain にまたがる4層のブロックチェーン C2 インフラを用いてリモートアクセス型トロイの木馬（RAT）を配信する。パッケージは2026年6月29日〜7月3日に公開されていた。

## 詳細

### 攻撃の手口

ViteVenom は、既知の npm サプライチェーン攻撃キャンペーン「ChainVeil」の拡張版と位置付けられている。脅威アクター「SuccessKey」によるものとされ、関連する暗号資産ウォレットは2026年2月27日には既に活動を開始していたことが確認されている。

パッケージは `@vitejs/` 名前空間を模倣したスコープ付きパッケージ名を使用し、開発者が正規パッケージと誤認するよう仕組まれていた。悪性コードはインストール時ではなく **インポート時** に実行される設計になっており、これによりエンドポイントセキュリティ製品による検知を回避しやすくしている。

### C2インフラの特徴

攻撃者はペイロードへのポインタをドメイン名ではなく、Tron・Aptos・Binance Smart Chain 上の**トランザクションデータとして格納**している。ドメインは押収やテイクダウンが可能だが、パブリックブロックチェーン上のトランザクションは削除・停止がほぼ不可能であり、インフラの耐久性を大幅に高めている。

### ペイロードの機能

配信される RAT は以下の機能を備える：
- リバースシェル
- 認証情報の窃取
- ファイルの外部送信
- 永続的なバックドアの埋め込み

### 関連する他の npm サプライチェーン攻撃

同時期には、@asyncapi npm組織を標的にした攻撃（7月14日）や、jscrambler npm パッケージが侵害された事案（7月11日）も報告されており、2026年7月は npm エコシステムを標的とした攻撃が相次いだ月となっている。

### 対策への示唆

フロントエンド開発者は `@vitejs/` 名前空間のパッケージをインストールする際、公式パッケージ名と完全一致するかを確認し、依存関係のロックファイルとサプライチェーンスキャンツール（Socket、Checkmarx 等）の活用が推奨される。
