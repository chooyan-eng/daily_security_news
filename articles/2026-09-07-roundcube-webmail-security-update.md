# Webメール「Roundcube」に12件の脆弱性、ゼロクリックXSSやSSRFフィルタ回避を修正

- **日付**: 2026-09-07
- **出典**: [Roundcube公式](https://roundcube.net/news/2026/09/06/security-updates-1.6.19-and-1.7.4), [Cyber Security News](https://cybersecuritynews.com/roundcube-webmail-patches-12-security-flaws/), [GBHackers](https://gbhackers.com/roundcube-fixes-12-security-flaws/)
- **トピック**: [Roundcube Webmail セキュリティアップデート（2026年9月）](../topics/roundcube-security-update-2026-09.md)
- **分類**: 新規

## 概要

オープンソースのWebメールクライアント「Roundcube」プロジェクトは2026年9月6日、1.6 LTS系列向けの1.6.19および1.7系列向けの1.7.4をリリースし、ゼロクリックの蓄積型XSSやSSRFフィルタ回避を含む12件の脆弱性を修正した。Roundcubeは多くの組織・ISPが自己ホスト型メールシステムとして採用しており、過去には国家関与とみられる攻撃キャンペーンの標的ともなっている。

## 詳細

今回修正された12件の脆弱性は、クロスサイトスクリプティング（XSS）、メールヘッダーインジェクション、ユーザー間の不正なデータアクセス、リモートコンテンツ読み込み制限のバイパス、サーバーサイドリクエストフォージェリ（SSRF）など多岐にわたる。

特に注目されるのが、添付ファイルURLへのTNEF MIMEタグ注入を悪用したゼロクリックの蓄積型XSSである。この脆弱性は被害者がメールを開くだけで（追加のクリック等の操作なしに）悪意あるスクリプトが実行される可能性があり、深刻度が高い。また、メールヘッダーインジェクションに関しては3種類の異なる手口が確認された。件名フィールドに含まれる裸のキャリッジリターン（CR）文字を利用するもの、宛先の表示名にC言語スタイルの `\r` エスケープシーケンスを埋め込むもの、そしてアイデンティティ（送信者情報）の組織名フィールドに細工した値を設定するものである。これらはいずれもメールヘッダーへの不正な値の注入につながりうる。

さらに、連絡先グループのメンバーシップ操作に存在するユーザー間アクセスの不備も修正された。この脆弱性により、本来は自分のアカウント内でのみ操作できるはずの連絡先グループメンバーに対し、他ユーザーの権限を超えて不正に干渉できる可能性があった。このほか、リモートコンテンツの読み込み制限のバイパスや、SSRFに関連するフィルタの回避手法も修正リストに含まれている。

Roundcubeを巡っては、過去に中国系とされる脅威アクター「UNK_MassTraction」が大学等のRoundcube導入環境を標的にした攻撃キャンペーンを展開した事例が報告されているなど、Webメールソフトウェアの脆弱性は標的型攻撃における初期侵入経路として現実に悪用されてきた実績がある。Roundcubeプロジェクトは、本番環境で1.6.x系列または1.7.x系列を運用している管理者に対し、速やかなアップデート適用を強く呼びかけている。
