# WP2Shell – WordPress コア脆弱性チェーン（CVE-2026-63030 / CVE-2026-60137）が未認証RCEとして実悪用

- **日付**: 2026-07-21
- **出典**: [The Hacker News](https://thehackernews.com/2026/07/new-wp2shell-wordpress-core-flaw-lets.html)
- **トピック**: [wp2shell WordPress コア RCE 脆弱性チェーン（2026年）](../topics/wp2shell-wordpress-core-rce-2026.md)
- **分類**: 続報
## 概要

WordPressコアに存在する2つの脆弱性を連鎖させることで、未認証の攻撃者がデフォルト設定・未改変のWordPressサイトを完全に乗っ取れる攻撃チェーン「WP2Shell」が発見され、2026年7月20日に実際の悪用がハニーポット上で観測された。ログインもプラグインのインストールも不要という深刻度の高さから、数千万サイトが影響を受けるとみられる。

## 詳細

### 脆弱性の内訳

- **CVE-2026-63030**：REST APIのバッチルート処理における混同（confusion）脆弱性
- **CVE-2026-60137**：WordPressコアに存在するSQLインジェクション脆弱性

この2つを連鎖させることで、匿名のHTTPリクエストのみからコード実行まで到達できる。

### 影響範囲

完全なRCEチェーンは以下のバージョンに影響する。
- WordPress 6.9.0 〜 6.9.4
- WordPress 7.0.0 〜 7.0.1

デフォルトインストールでも悪用可能であり、追加のプラグインや脆弱な設定は不要。

### 悪用状況

セキュリティ企業Coalitionは2026年7月20日、自社ハニーポット上でWP2Shellの積極的な悪用を観測したと報告した。攻撃者は匿名リクエストからチェーンを実行し、任意コードの実行に成功している。

### ベンダー対応

WordPressはバージョン6.9.5および7.0.2をリリースし、脆弱性を修正した。影響の深刻さを踏まえ、WordPressの自動更新システムを通じた強制アップデート（forced updates）を有効化し、未対応サイトへの自動パッチ適用を進めている。

### 推奨対策

- WordPressコアを6.9.5または7.0.2以降へ即時更新
- 自動更新が無効化されている環境では手動での緊急パッチ適用
- REST APIバッチエンドポイントへの異常なリクエストパターンの監視
- WAF等でのSQLインジェクション試行の検知強化
