# 暗号資産取引テック企業Haruko、標的型サイバー攻撃で顧客15社のAPI情報・取引データが流出

- **日付**: 2026-09-21
- **出典**: [CoinDesk](https://www.coindesk.com/business/2026/09/18/crypto-tech-provider-haruko-hit-by-cyberattack-affecting-15-clients-some-funds-lost), [CryptoTimes](https://www.cryptotimes.io/2026/09/18/haruko-cyberattack-exposes-api-data-across-15-crypto-clients/)
- **トピック**: [Haruko 標的型サイバー攻撃によるAPI情報・取引データ流出事案（2026年9月）](../topics/haruko-crypto-tech-breach-2026.md)
- **分類**: 新規

## 概要

ロンドン拠点の暗号資産トレーディング向けテクノロジー企業Harukoが標的型サイバー攻撃を受け、顧客15社の読み取り専用取引所API情報や取引データが流出、一部顧客の資金も少額ながら窃取された。攻撃者はHarukoの内部プロセスの脆弱性を突いてユーザーアクセストークンを取得し、プロセスメモリ上のデータを窃取したとみられる。

## 詳細

Harukoは、機関投資家やヘッジファンド向けに暗号資産取引の執行・ポートフォリオ管理ツールを提供するロンドン拠点のテクノロジー企業。2026年9月18日、同社は標的型サイバー攻撃を受けたことを公表した。

報道によれば、攻撃者はHarukoの特定プロセスに存在する脆弱性を悪用し、ユーザーアクセストークンを窃取。このトークンを用いてプロセスメモリ内に保持されていたデータへアクセスし、顧客の取引所API情報（読み取り専用）や取引データを取得した。影響を受けたのはホワイトリスト設定を行っていなかった全ての顧客で、合計15社に上る。

流出した情報には各顧客の取引所API接続情報や取引記録が含まれるが、顧客自身のシステム上でログイン認証情報そのものが侵害されたわけではないとされる。もっとも、報道では少額ながら顧客資金の窃取も発生したとされており、セキュリティ管理体制が比較的弱いとみられる小規模ヘッジファンド顧客が特に影響を受けやすかった可能性が指摘されている。

Harukoは脆弱性を修正済みであるとし、サーバー側のシークレット情報（APIキーや認証トークン等）を全て再発行する対応を実施したと説明している。窃取された資金の正確な規模は公式には明らかにされていない。

本事案は、暗号資産取引そのものではなく、取引所APIとの連携を仲介するサードパーティ製SaaS型インフラが攻撃対象となった点で、暗号資産エコシステムにおけるサプライチェーンリスクの一例として位置づけられる。

**同一性の判断に役立つ情報：**
- 対象企業: Haruko（ロンドン拠点、暗号資産トレーディング向けテクノロジー企業）
- 影響範囲: 顧客15社（ホワイトリスト非設定の全顧客）
- 侵害手口: 内部プロセスの脆弱性悪用によるユーザーアクセストークン窃取→プロセスメモリ上のデータ取得
- 流出情報: 読み取り専用の取引所API情報、取引データ
- 被害: 一部顧客の資金が少額窃取
- 公表日: 2026年9月18日
- 対応: 脆弱性修正、サーバー側シークレットの再発行
