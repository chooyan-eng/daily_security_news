# セイコーソリューションズ製ルーター「SkyBridge」シリーズに複数の脆弱性、一部は無償修正パッチなし

- **日付**: 2026-07-03
- **出典**: [ScanNetSecurity](https://scan.netsecurity.ne.jp/article/2026/07/03/55626.html), [JVN](https://jvn.jp/jp/JVN40604023/)
- **トピック**: [セイコーソリューションズ SkyBridge/SkySpider 脆弱性（2026年）](../topics/seiko-skybridge-vulnerabilities-2026.md)
- **分類**: 新規

## 概要

セイコーソリューションズが提供するルーター製品「SkyBridge」シリーズ（MB-A100/A110/A200/BASIC MB-A130）およびSkySpider（MB-R210）に、OSコマンドインジェクションを含む複数の脆弱性が確認された。SkyBridge BASIC MB-A130ではWeb管理画面から認証なしで任意のOSコマンドを実行可能（CVSSv3で9.8）。旧型機種の一部はサポート終了済みで修正パッチが提供されない。

## 詳細

### 脆弱性の詳細

JVN（Japan Vulnerability Notes）およびScanNetSecurityの報道によると、セイコーソリューションズ製のルーター製品群に複数の脆弱性が確認された。対象製品は以下の通り。

- SkyBridge MB-A100
- SkyBridge MB-A110
- SkyBridge MB-A200
- SkyBridge BASIC MB-A130
- SkySpider MB-R210

中でも深刻度が高いのはSkyBridge BASIC MB-A130（バージョン1.5.8以前）に存在する脆弱性で、Web管理画面を通じて認証なしに任意のOSコマンドを実行できる。CVSSスコアはv3.0で9.8、v4.0で9.3と評価されており、最大深刻度に区分される。

### 対応状況

SkyBridge BASIC MB-A130については、修正版バージョン1.6.0以降へのアップデートが提供されており、利用者には速やかな適用が推奨されている。

一方、SkyBridge MB-A100およびMB-A110についてはすでにサポートが終了しており、修正パッチの提供予定がないことが公表されている。有効な回避策も示されておらず、該当機種を継続利用しているユーザーは、後継機種への切り替えやネットワーク的な隔離（管理画面へのアクセス制限等）を検討する必要がある。

### リスクの所在

ルーター製品はインターネットと内部ネットワークの境界に位置することが多く、Web管理インターフェースの認証不備・コマンドインジェクションは、外部からの侵入拠点として悪用されるリスクが高い。国内の中小企業や店舗網などで広く使われている機種である場合、影響範囲は無視できない規模になる可能性がある。
