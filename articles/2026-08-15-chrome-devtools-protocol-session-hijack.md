# Chrome DevTools Protocolを悪用した新たなセッションハイジャック手法「CDP-Enable-BOF」が公開

- **日付**: 2026-08-15
- **出典**: [The Hacker News](https://thehackernews.com/2026/08/chrome-devtools-technique-enables.html)
- **トピック**: [Chrome DevTools Protocol悪用セッションハイジャック手法（2026年）](../topics/chrome-devtools-protocol-session-hijack-2026.md)
- **分類**: 新規

## 概要

セキュリティ企業SpecterOpsが、Windows上で稼働中のGoogle Chrome / Microsoft Edgeプロセスの内部からChrome DevTools Protocol（CDP）を有効化し、Cookieや保存データ、認証済みブラウザセッションにアクセスするポストエクスプロイト手法「CDP-Enable-BOF」を公開した。2026年8月14日発表。

## 詳細

### 前提条件

本手法はChromeやEdge自体のセキュリティ脆弱性を悪用するものではない。攻撃者がWindowsホスト上で既にコード実行権限を得ていることを前提とするポストエクスプロイト（侵害後）技術であり、既存の防御を回避してDevToolsのデバッグサーバーを起動中の`chrome.exe`または`msedge.exe`プロセス内部から直接有効化する点が特徴。

### 主な機能

- **Cookie収集**: `Storage.getCookies` を使用し、ディスク上のCookieデータベースを直接読み取ることなくブラウザのCookie状態を取得
- **ブラウザデータ収集**: CDPおよびブラウザ描画ページを通じて、閲覧履歴・ブックマーク・インストール済み拡張機能・スクリーンショット・保存パスワードのメタデータを取得可能
- **保存パスワードの復元**: Chromiumのオートフィル機構を対象オリジンに対して動作させ、ユーザー名・パスワードのフィールド値をCDP経由で取得
- **ブラウザ乗っ取り**: オフスクリーンまたはバックグラウンドのブラウザターゲットを作成し、インタラクティブなスクリーンキャストや、被害者の認証済みセッションを保持したままのHTTP/HTTPSリクエストのプロキシ転送が可能

### 検知

SpecterOpsは、防御側が`chrome.exe`・`msedge.exe`を標的としたプロセスインジェクションの兆候を、Sysmon イベントID 8（リモートスレッド作成）およびID 10（プロセスアクセス）で検知できるとしている。

### リスクと対策

- ブラウザに保存された認証情報・セッションCookieはEDR等の従来型対策の死角になりやすく、既に侵害された端末上での横展開・権限昇格に悪用され得る
- ブラウザプロセスへの異常なプロセスインジェクションの監視強化
- 可能であればブラウザの保存パスワード機能を無効化し、専用パスワードマネージャーの利用を徹底する
- 高価値アカウントについてはFIDO2等のフィッシング耐性のある認証方式への移行を検討する
