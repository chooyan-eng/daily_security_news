# 新PhaaS「Forg365」、デバイスコードフィッシングとAiTMでMicrosoft 365アカウントを標的に

- **日付**: 2026-07-13
- **出典**: [The Hacker News](https://thehackernews.com/2026/07/forg365-phaas-targets-microsoft-365.html), [BleepingComputer](https://www.bleepingcomputer.com/news/security/new-forg365-phishing-platform-uses-ai-to-target-microsoft-365-accounts/)
- **トピック**: [デバイスコードフィッシング / AiTM セッショントークン窃取（2026年）](../topics/device-code-phishing-aitm-2026.md)
- **分類**: 続報

## 概要

Telegramで販売される新たなフィッシング・アズ・ア・サービス（PhaaS）「Forg365」が確認された。デバイスコード認証フローの悪用とAiTM（Adversary-in-the-Middle）セッション窃取を組み合わせ、Microsoft 365アカウントを標的とする。月額400ドル・年額3,800ドルで提供され、AIによるフィッシングメール生成、アンチボット回避、侵害後のメールボックス操作機能まで含む一体型の攻撃キットとなっている。

## 詳細

### 提供形態と価格

Forg365はTelegram経由で流通しており、5日間の無料トライアル、月額400ドル、年額3,800ドルのサブスクリプションモデルを採用している。ダッシュボードから新規フィッシングキャンペーンの作成、フィッシングリンクの管理、OAuthアプリやSMTPプロファイルの設定、トークン管理、AIを用いたフィッシングメール文面の生成までを一元的に行える。

### デバイスコードフィッシング機能

Forg365にはデバイス認証フィッシング専用の機能があり、Microsoft風の検証コードページを表示した上で、被害者を正規のMicrosoft Authentication Brokerのサインインフローへ誘導する。被害者からは本物のMicrosoft認証画面に見えるが、実際には表示されたコードが攻撃者側の管理するセッションを認可してしまう仕組みになっている。

### AiTM機能

AiTMフィッシングでは、ルートトークン・セッションクッキー・トラフィック分類を用いて、アクセス元がVPN経由かどうかを判定し、VPN検出時にはフィッシングページの代わりに無害なデコイコンテンツへリダイレクトすることでセキュリティ調査を回避する設計となっている。

### 侵害後の永続化機能

ChromiumベースのブラウザGoogle Chrome・Microsoft Edge・Brave向けの拡張機能「ForgCookie」も提供されており、侵害済みアカウントへの継続的なアクセスを維持する目的で使われる。

### 既存トピックとの関連

本件は、2026年6月に37倍の検出スパイクを記録したOAuth 2.0デバイス認証フロー悪用型AiTM攻撃（デバイスコードフィッシング）のコモディティ化がさらに進行していることを示す事例である。同種の攻撃キットが少なくとも18種類確認されている状況の中、Forg365はAI支援機能や侵害後の運用機能まで統合した、より高機能なサービスとして登場した。

### 対策

- FIDO2セキュリティキーなど、AiTMやデバイスコードフィッシングに耐性のある認証方式への移行を検討すること
- デバイスコード認証フローの利用を組織ポリシーで制限・監視すること
- 侵害後の永続化を狙うブラウザ拡張機能のインストールを監視・制限すること
