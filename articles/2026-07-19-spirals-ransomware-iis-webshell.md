# 新型ランサムウェア「Spirals」、公開 IIS Web サーバー侵害から24時間以内に暗号化を完了

- **日付**: 2026-07-19
- **出典**: [BleepingComputer](https://www.bleepingcomputer.com/news/security/new-spirals-ransomware-encrypts-victim-network-in-under-24-hours/)
- **トピック**: [Spirals ランサムウェア（2026年）](../topics/spirals-ransomware-2026.md)
- **分類**: 新規

## 概要

新たに確認されたランサムウェア「Spirals」を用いる脅威アクターが、南アジアの IT サービス企業に対し、インターネットに公開された IIS Web サーバーの侵害から情報窃取・暗号化まで24時間未満で完了させる侵入を実行した。ASP.NET Web シェルの設置、UAC バイパス、WMI を用いた横展開など一連の手口を組み合わせ、Rust 製のランサムウェアにより大容量ファイルを高速に暗号化した。

## 詳細

### 侵入の経緯

侵入は2026年6月16日22時21分（現地時間）に開始された。攻撃者はインターネットに公開されていた Internet Information Services（IIS）Web サーバーを侵害し、ASP.NET 製の Web シェルをアップロードした。

### 権限昇格と永続化

Spirals のオペレーターはその後、ユーザーアカウント制御（UAC）をバイパスし、リモートデスクトップを有効化、ローカルアカウントを新規作成することで永続的なアクセス経路を確保した。さらにホスト上のセキュリティソフトの除去を試み、WMI（Windows Management Instrumentation）を用いて12台以上のシステムへ横展開した。冗長なリモートアクセス経路として revsocks、Chisel、Cloudflare トンネルを複数確立している。

### ランサムウェアの技術的特徴

Spirals は Rust で実装されたランサムウェアファミリーであり、5MB を超えるファイルに対しては断続的暗号化（intermittent encryption）を採用することで暗号化処理を高速化している。暗号鍵は攻撃者が管理する ECDH P-256 公開鍵で保護された AES-128 鍵を用いる。暗号化完了後には C ドライブ直下に `RECOVERY_SECTION.log` という名称の身代金メモが設置され、身代金交渉の手順が記載される。窃取データについては、支払いに応じない場合6日以内に公開すると脅迫する二重恐喝の手口を採用している。

### 攻撃の速度

初期侵入から情報窃取・暗号化完了までを24時間未満で達成しており、公開 Web サーバーの侵害から本格的なランサムウェア展開までの時間が近年ますます短縮化している傾向を象徴する事例として注目されている。

### 推奨対策

- インターネットに公開している IIS サーバーのパッチ適用状況を確認し、不要な公開を最小化する
- Web シェル検知のための Web アプリケーションファイアウォール（WAF）・EDR の導入
- UAC バイパスやローカルアカウント作成などの異常な権限昇格活動の監視
- WMI を用いた横展開の検知ルールの整備
- インシデント対応の初動を24時間未満の侵入速度を前提として設計する
