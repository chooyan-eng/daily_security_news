# Injective Labs の GitHub リポジトリが侵害、npm 経由で暗号資産ウォレット窃取パッケージが配布

- **日付**: 2026-07-12
- **出典**: [The Hacker News](https://thehackernews.com/2026/07/injective-labs-github-compromise-pushes.html)
- **トピック**: [npmサプライチェーン攻撃・暗号資産ウォレット窃取（2026年7月）](../topics/npm-supply-chain-crypto-wallet-2026.md)
- **分類**: 新規

## 概要

DeFi向けブロックチェーン基盤 Injective の公式SDKを提供するGitHubリポジトリが侵害され、npmパッケージ「@injectivelabs/sdk-ts」の悪意あるバージョン（1.20.21）が公開された。このパッケージは暗号資産ウォレットの秘密鍵とニーモニックシードフレーズを窃取し、外部に送信する機能を持つ。関連する17個のスコープ付きパッケージにも影響が波及した。

## 詳細

### 侵害の概要

Injective Labs SDKプロジェクトのGitHubリポジトリが何らかの方法で侵害され、npmレジストリ上の「@injectivelabs/sdk-ts」パッケージのバージョン1.20.21として悪意あるコードが2026年7月8日に公開された。同SDKはInjectiveブロックチェーン（DeFi・トークン化資産・分散型取引所に特化したレイヤー1ブロックチェーン）上でアプリケーションを構築するためのTypeScript/JavaScript製SDKで、週間ダウンロード数は約5万件に上る。

セキュリティ企業Socket、Ox Security、StepSecurityがこの侵害を検知し報告した。

### マルウェアの機能

悪意あるバージョンは、インストール時に暗号資産ウォレットの完全なニーモニックシードフレーズと秘密鍵を取得し、Base64でエンコードした上でInjective Labsの公式インフラのエンドポイントに見せかけたHTTP POSTリクエストとして外部送信する。正規のインフラを装うことで、通信を検知しにくくする狙いがあるとみられる。

### 影響範囲

攻撃者は同じ悪意あるバージョン1.20.21を、@injectivelabsスコープ配下の依存関係を持つ他の17個のパッケージにも展開しており、直接このSDKをインストールしていない開発者も、これらの依存パッケージ経由で間接的に影響を受ける可能性がある。公式統計によれば、悪意あるバージョンのダウンロード数は310件と報告されている。

このSDKは暗号資産ウォレット、トレーディングボット、分散型取引所（DEX）、DeFiアプリケーション、決済ツールを構築する開発者に広く利用されており、影響範囲は暗号資産関連の開発者コミュニティ全体に及ぶ。

### 推奨対応

このパッケージをインストールした可能性がある開発者に対しては、保有する暗号資産を新しいウォレットへ即座に移動すること、および開発環境内の全シークレット（APIキー・トークン等）のローテーションが強く推奨されている。
