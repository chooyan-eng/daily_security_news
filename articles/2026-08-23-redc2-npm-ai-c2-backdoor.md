# 14件のnpmパッケージがトロイ化、AI搭載C2フレームワーク「RedC2 4.0」のLinuxバックドアを配布

- **日付**: 2026-08-23
- **出典**: [The Hacker News](https://thehackernews.com/2026/08/14-trojanized-npm-packages-drop-redc2.html)
- **トピック**: [RedC2 npmサプライチェーン攻撃（2026年8月）](../topics/redc2-npm-supply-chain-2026.md)
- **分類**: 新規

## 概要

セキュリティ研究者が、カレンダー・連続記録（streak）管理などの実用ツールを装った14件のnpmパッケージが、AI搭載のLinux向けインプラント「RedC2 4.0」を密かに配布していたことを確認した。攻撃者はRed Offsecが提供する市販レッドチームツールを悪用しており、脅威アクター「MarlboroMan」との関連が指摘されている。

## 詳細

### 攻撃の概要

問題のnpmパッケージは、開発者が日常的に利用するカレンダー機能やストリーク（連続記録）管理といった無害な実用ツールを装っていた。パッケージをインポートすると、Linux向けの「RedShell」ビーコンが起動する仕組みになっており、被害者の開発環境やサーバーに侵入経路を確立する。

### RedShellビーコンの機能

RedShellのLinux版ビーコンは、`/bin/sh`を通じた対話型シェルを提供し、システム探索・ファイル操作・データ収集（SSHキーやブラウザ認証情報を含む）・コマンド実行・永続化・メモリ内でのELFファイル実行・SOCKS5プロキシ・ネットワークピボッティングといったLinux特化のコマンド群を備える。

### AIアシスタント「Red Agent」

RedC2 4.0の特徴的な機能が、LLM（大規模言語モデル）を活用したコマンド実行レイヤー「Red Agent」である。攻撃者はレッドチーム運用向けに調整されたモデルに対して自然言語でプロンプトを入力するだけで、フレームワークがそれを実行可能なビーコンコマンド列に自動変換する。これにより、高度な技術知識がなくても複雑な侵害後の操作を実行できるようになっている。

### フレームワーク全体の機能

RedC2は、ターミナルアクセス・ファイル転送・段階的なペイロード配信・データ収集・複数ビーコンの同時運用・ネットワーク可視化・ホスト間トンネリング、さらにBOF（Beacon Object Files）・.NETアセンブリ・シェルコードのメモリ内実行など、非常に高機能なC2（コマンド&コントロール）フレームワークである。本来は正規のレッドチーム演習用ツールとしてRed Offsecが市販しているものだが、今回はこれが悪用され、npmエコシステムを通じた実際の攻撃に転用された。

### サプライチェーンへの影響

開発者がnpmパッケージを日常的にインポートする際に自動実行されるコードを通じて感染するため、パッケージの中身を精査しないまま導入した組織では、CI/CD環境や本番サーバーへの侵入を許すリスクがある。AIを活用したC2運用の実用化は、攻撃者側の技術的ハードルをさらに下げるものであり、今後同種の手口が拡大する可能性がある。

### 対策

開発者・組織に対しては、依存パッケージの発行元・更新履歴・ダウンロード数などの異常を確認するサプライチェーン監査の徹底、未知のpreinstall/postinstallスクリプトやrequire時の不審な挙動を検知するツールの導入、CI/CD環境における最小権限原則の適用が推奨される。
