# Google、Chrome安定版で高深刻度脆弱性12件を修正 うち2件はAIが発見

- **日付**: 2026-07-21
- **出典**: [Cyber Security News](https://cybersecuritynews.com/chrome-update-fixes-12-vulnerabilities/)
- **トピック**: [Chrome定例セキュリティアップデート（2026年7月）](../topics/chrome-stable-security-update-2026-07.md)
- **分類**: 新規

## 概要

Googleは2026年7月21日、Chrome安定版（バージョン150.0.7871.181/.182）で高深刻度（High）の脆弱性12件を修正するセキュリティアップデートを公開した。WebAudio・ANGLE・V8・Skia・拡張機能・GPUプロセスなど広範なコンポーネントに影響するメモリ安全性の不具合が対象。うち2件は自律型AIセキュリティ研究システム「XBOW」が発見しており、脆弱性発見の自動化が実用段階に入りつつあることを示す事例となった。野生での悪用や実証コードの公開は確認されていない。

## 詳細

### アップデート概要

今回のアップデートはWindows・Mac向けにバージョン150.0.7871.181/.182、Linux向けに150.0.7871.181として提供された。修正された脆弱性はCVE-2026-16413からCVE-2026-16424までの範囲で採番されており、いずれも「High」（クリティカルではない）評価となっている。GoogleはCritical評価をサンドボックスからの脱出を伴う脆弱性のために予約しており、今回の12件はいずれもそれには該当しない。

### 影響コンポーネント

修正対象にはWebAudio、ANGLE（グラフィックスレイヤー）、V8 JavaScript/WebAssemblyエンジン、Skia（描画エンジン）、拡張機能サブシステム、Chromecast関連機能、証明書処理、GPUプロセス、UIコンポーネントなど広範な範囲が含まれる。報告された不具合の種別には型の混同（type confusion）、境界外書き込み（out-of-bounds write）、解放後使用（use-after-free）、整数オーバーフロー、未初期化メモリの使用など、典型的なメモリ安全性バグが並ぶ。

### AIによる脆弱性発見

12件のうち2件（CVE-2026-16420、CVE-2026-16421）は、自律型AI駆動のセキュリティ研究システム「XBOW」によって発見され、研究者Brendan Dolan-Gavitt氏がトリアージを行った。発見者にはそれぞれ500ドルの報奨金が支払われている。残る10件は2026年5月下旬から7月中旬にかけてGoogle社内のセキュリティチームによって発見されたものである。

### 悪用状況

Googleは、これら12件の脆弱性についていずれも野生（in the wild）での悪用や、公開された実証コード（PoC）は確認されていないとしている。ユーザーには通常のブラウザ更新プロセスを通じた早期のアップデート適用が推奨される。
