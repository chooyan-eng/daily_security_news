# Entraパスキー登録を悪用したビッシング攻撃がMicrosoft 365ユーザーを標的に — 攻撃者「O-UNC-066」（Pink）

- **日付**: 2026-07-08
- **出典**: [BleepingComputer](https://www.bleepingcomputer.com/news/security/entra-passkey-enrollment-vishing-targets-microsoft-365-users/)（Okta調査）
- **トピック**: [デバイスコードフィッシング / AiTM セッショントークン窃取（2026年）](../topics/device-code-phishing-aitm-2026.md)
- **分類**: 関連

## 概要

Okta が「O-UNC-066」（別名「Pink」）として追跡する脅威アクターが、2026年4月頃から複数業種の組織を標的に、電話（ビッシング）でユーザーを騙し攻撃者制御下の Microsoft Entra パスキーを登録させる攻撃キャンペーンを展開している。Microsoft が5月に管理者向けに開放した「パスキー登録キャンペーン」機能を悪用し、正規のパスキー登録プロセスを模したフィッシングキットへユーザーを誘導する。

## 詳細

### 攻撃の仕組み

1. 攻撃者は対象ユーザーへ電話をかけ、セキュリティ上の理由を装って新しいパスキーの登録を求める
2. ユーザーは Microsoft のパスキー登録プロセスを精巧に模したフィッシングキットへ誘導される
3. ユーザーは「自分のアカウントに新しいパスキーを登録している」と信じているが、実際には攻撃者が制御するパスキーを登録させられている
4. 攻撃者はこのパスキーを用いて被害者のアカウントへ不正アクセスする

このフィッシングキットはオペレーター制御型のPHPパネルで構成されており、攻撃者は被害者が使用しているMFA方式に応じてリアルタイムでフローを調整しながらフィッシングを進行させる。

### Microsoftの新機能の悪用

攻撃者は、Microsoftが2026年5月に管理者向けに提供を開始した「パスキー登録キャンペーン」機能（より安全な認証のためユーザーにパスキー登録を促す正規機能）の存在と文脈を逆手に取り、ユーザーの警戒心を下げている。

### 脅威アクターと標的

- **追跡名**: O-UNC-066（Okta による命名）、別名「Pink」
- **主な動機**: データ恐喝（exfiltration-based extortion）
- **標的業種**: 食品・飲料、テクノロジー、ヘルスケア、自動車、建設、航空の各業種
- **活動開始**: 2026年4月頃〜

### 既存トピック（デバイスコードフィッシング/AiTM）との関連

本件は OAuth デバイス認証フローを悪用する「デバイスコードフィッシング」とは異なる手法（音声によるソーシャルエンジニアリング＋パスキー登録の悪用）だが、いずれも Microsoft 365 / Entra ID を標的とし、パスワードやMFAといった従来の防御を回避してアカウントを乗っ取るという共通の脅威トレンドに属する。

### 対策

- パスキー登録を求める電話連絡には応じず、正規の管理コンソールから直接操作する
- 管理者は「パスキー登録キャンペーン」機能利用時、ユーザーへの事前周知を徹底する
- 異常なパスキー登録イベントの監査ログ監視
