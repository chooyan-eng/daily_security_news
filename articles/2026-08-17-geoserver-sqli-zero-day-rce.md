# GeoServer 未認証SQLインジェクション ゼロデイ、RCEに繋がる脆弱性が積極的悪用下に

- **日付**: 2026-08-17
- **出典**: [The Hacker News](https://thehackernews.com/2026/08/unpatched-geoserver-zero-day-targeted.html)
- **トピック**: [GeoServer 未認証SQLインジェクション ゼロデイ（2026年8月）](../topics/geoserver-sqli-zero-day-2026.md)
- **分類**: 新規

## 概要

オープンソースの地理空間データ配信プラットフォーム GeoServer に、未認証で悪用可能な SQL インジェクション脆弱性（CVSS 9.8、GHSA-mqjf-5f49-2fjh）が発見された。8月12日の公開直後から偵察目的とみられる悪用試行が観測されており、条件次第でリモートコード実行（RCE）に繋がる。開発チームは修正版をリリース済み。

## 詳細

### 脆弱性の内容

脆弱性は GeoServer が OGC Filter を処理する際、PostGIS DataStore 実装の `jsonArrayContains` 関数を経由して SQL クエリを組み立てる過程に存在する。攻撃者は認証なしで細工した OGC Filter リクエストを送信するだけで任意の SQL 文を注入でき、データベース権限やドライバー構成によっては OS コマンド実行（RCE）まで到達しうる。CVSS スコアは 9.8（Critical）。

### 開示と悪用の経緯

- **8月12日 10:46 UTC**: 研究者 @q1uf3ng（X/Twitter）が脆弱性の詳細を公開。この時点でトラディショナルな CVE 番号は未採番で、GitHub Security Advisory（GHSA-mqjf-5f49-2fjh）として管理されている。
- **公開直後〜数時間以内**: 少数の IP アドレス群から数百件規模の悪用試行が確認された。セキュリティ企業によれば、現時点では本格的なペイロード投下よりも偵察目的のプローブが中心とみられる。
- GeoServer 側は修正版として **3.0.1・2.28.5・2.27.6** をリリース済み。

### 影響範囲

GeoServer は自治体・研究機関・インフラ事業者など、地理空間データを Web 経由で公開する用途で広く使われている。PostGIS DataStore を利用し、かつインターネットに露出した構成のインスタンスが特にリスクが高い。

### 推奨対応

- 該当バージョンを直ちに 3.0.1 / 2.28.5 / 2.27.6 以降へアップデート
- 緊急パッチが適用できない場合は、GeoServer インスタンスをインターネットから隔離、または WAF でフィルタリクエストを検査
- アクセスログを確認し、OGC Filter 経由の異常なリクエストパターンがないか調査
