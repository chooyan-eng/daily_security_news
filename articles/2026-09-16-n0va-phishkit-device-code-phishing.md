# 新型フィッシングキット「N0va」、デバイスコード認証悪用で北米・欧州企業を標的に

- **日付**: 2026-09-16
- **出典**: [The Hacker News](https://thehackernews.com/2026/09/n0va-phishkit-targets-us-and-eu.html)
- **トピック**: [新型フィッシングキット「N0va」デバイスコード／AiTM認証悪用キャンペーン（2026年9月）](../topics/n0va-phishkit-device-code-phishing-2026.md)
- **分類**: 新規

## 概要

セキュリティ研究者は、北米・欧州の政府・技術・コンサルティング・医療等の組織を標的とする新型フィッシングキット「N0va」の活動を確認した。業務で日常的に使うツールを装う誘導により、Microsoft正規のサインインフローを悪用したデバイスコード／AiTM型認証を実行させ、有効なアクセス・リフレッシュトークンを窃取する手口である。

## 詳細

N0vaは、Microsoft Teams、SharePoint、OneDrive、DocuSign、Google Drive、Dropbox、Zoom、Adobe Signといった従業員が日常的に利用するツールになりすましたルアー（誘導文言・画面）を用いる点が特徴である。攻撃はまず攻撃者側が認証リクエストを開始し、被害者にMicrosoftの正規サインインインフラを通じてそれを完了させるよう誘導する。被害者は多要素認証（MFA）を含む認証手続きを自ら完了させてしまうが、実際には攻撃者が開始したセッションを承認する形になっており、結果として攻撃者は有効なアクセストークン・リフレッシュトークンを取得する。

この手口の危険性は、明白なマルウェアの実行を伴わずに正規の認証情報でアカウントへアクセスできてしまう点にある。侵害されたアカウント一つから、機密データや業務システム、さらなるクラウドリソースへのアクセス拡大につながるおそれがある。

研究者らは、N0vaの攻撃インフラが侵害された正規ウェブサイト、Cloudflare Workers、Linode Object Storageに分散配置されていることも確認しており、検知や遮断を困難にする設計となっている。

デバイスコードフィッシングやAiTM（Adversary-in-the-Middle）型のセッショントークン窃取は、パスワードやMFAを正面から破らずに正規の認証成功をなりすます手口として、企業の重要SaaS・クラウド環境を狙う攻撃で継続的に確認されている手法群の一つであり、N0vaはその最新の実装例と位置付けられる。
