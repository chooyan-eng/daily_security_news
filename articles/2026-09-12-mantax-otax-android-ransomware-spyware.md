# Android向け新種マルウェア「Mantax Otax」、ランサムウェアとスパイウェアを統合しインドネシア利用者を標的に

- **日付**: 2026-09-12
- **出典**: [Zimperium](https://zimperium.com/blog/mantax-otax-indonesian-mobile-ransomware-with-spyware-integration), [BleepingComputer](https://www.bleepingcomputer.com/news/security/new-android-malware-encrypts-files-steals-data-and-harasses-victims/), [GBHackers](https://gbhackers.com/mantax-otax-android-ransomware/)
- **分類**: 新規

## 概要

モバイルセキュリティ企業Zimperiumが、ランサムウェア機能とスパイウェア機能を統合した新種のAndroidマルウェア「Mantax Otax」を発見した。インドネシアの利用者を主な標的とし、公式ストア外で配布されるAPKを通じて感染する。端末内ファイルの暗号化や画面ロックに加え、SMSやOTP、写真、位置情報などの個人情報を密かに窃取し、被害者を脅迫・嫌がらせする二重恐喝型の挙動を示す。

## 詳細

Mantax Otaxは、Zimperium社のモバイル脅威研究チーム「zLabs」が発見・分析したAndroid向けマルウェアで、インドネシアの利用者をターゲットとしたフィッシングやソーシャルエンジニアリングのメッセージを通じて、Google Play以外の場所でホストされる悪意あるAPKファイルとして配布される。

インストール直後、マルウェアは端末管理者（デバイスアドミニストレーター）権限を要求する。この際に表示される許可プロンプトには、全データの消去、画面ロックの変更、画面のロック、カメラの無効化といった強力な権限が明示されており、被害者が十分な注意を払わずに許可してしまうケースが想定される。続いてカメラ、SMSメッセージ、連絡先、音声、画像へのアクセス権限、および他アプリの上に重ねて表示する権限を要求する。

権限取得後、Mantax Otaxは端末内のファイルを暗号化し、画面をロックした上で、被害者を攻撃者とのチャット画面へ強制的に誘導する。これと並行して、画面ロックPIN、SMSメッセージ、ワンタイムパスワード（OTP）、ブラウザ履歴、連絡先、通話履歴、インストール済みアプリの一覧、Googleアカウント情報、位置情報などを密かに窃取する。さらに、Android の MediaProjection API を悪用して画面内容を録画するほか、前面・背面カメラで画像を撮影し、WhatsAppやTelegramの利用状況を監視する機能も備える。

コマンド＆コントロール（C2）インフラの取得には、GitHub上のリポジトリを悪用する手法が用いられており、感染端末は位置情報、通信キャリア、Androidバージョン、端末IDなどの情報をC2サーバーへ送信する。ランサムウェアとスパイウェアの機能を一体化させることで、身代金を支払わない被害者に対しては窃取した機微情報（性的な内容を含む写真やメッセージ履歴等）を用いた恐喝・嫌がらせに発展する可能性があり、従来の暗号化のみのランサムウェアより深刻な二次被害につながるおそれがある。研究者は、公式ストア以外からのAPKインストールを避け、不審なアプリへの端末管理者権限付与を行わないよう注意を呼びかけている。
