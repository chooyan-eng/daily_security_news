# 公開されたAWSアクセスキー9,300件超が依然有効、Truffle Securityが大規模調査

- **日付**: 2026-08-22
- **出典**: [BleepingComputer](https://www.bleepingcomputer.com/news/security/hundreds-of-leaked-aws-keys-give-full-control-over-corporate-accounts/) / [Cybernews](https://cybernews.com/security/major-security-oversight-88-of-leaked-aws-keys-still-work/)
- **トピック**: [公開AWSアクセスキー放置問題（Truffle Security調査、2026年）](../topics/aws-exposed-access-keys-truffle-2026.md)
- **分類**: 新規

## 概要

セキュリティ企業Truffle Securityが、2022年8月から2026年8月の間にGitの履歴やHugging Faceデータセット、Dockerイメージ、パッケージレジストリ、CI/CDログなど公開領域から見つかったAWSアクセスキーを再検証した結果、10,616件のうち88%にあたる9,300件超が依然として有効だったと報告した。

## 詳細

### 調査の概要

Truffle Securityは、過去4年間にわたり公開リポジトリやクラウドサービス上で見つかったAWSアクセスキーペアを収集し、2026年8月10日に再検証を実施した。対象となった10,616件のキーペアのうち、実に88%（約9,300件）が今なお有効な認証情報として機能することが確認された。

### 深刻度の内訳

漏洩したキーのうち817件は特定の企業に紐づくものであり、そのうち526件はAWSアカウントのルートキーであった。さらに242件は「AdministratorAccess」ポリシーを付与されたIAMユーザーに関連しており、これはAWSアカウント内のほぼ全サービス・リソースの作成・変更・削除・閲覧が可能な、事実上無制限の権限を意味する。

### キーの経過年数とローテーション状況

作成日が判明している2,903件のキーについて、経過期間の中央値は約1,831日（およそ5年）に達し、最も古いものは17.4年間有効なまま放置されていた。同一ユーザーに新しいアクセスキーが発行されていた事例はわずか398件（13.7%）にとどまり、大半のキーが一度もローテーションされていないことが示された。

### 漏洩経路

漏洩キーの発見元は、公開されたGitのコミット履歴、Hugging Face上のデータセット、Dockerイメージ、パッケージレジストリ、CI/CDのビルドログなど多岐にわたる。開発者がテストやデバッグの過程で誤ってハードコードした認証情報が、そのまま公開リポジトリやコンテナイメージに残存し続けているケースが多数を占める。

### リスクと対応

長期間有効なまま放置された高権限キーは、ひとたび第三者に発見・悪用された場合、クラウド環境全体の掌握や大規模なデータ持ち出しにつながりかねない。Truffle Securityは、認証情報の露見を前提とした定期的なローテーション運用と、公開リポジトリへのシークレットのコミットを防ぐスキャンツールの導入を推奨している。特にルートキーやAdministratorAccess権限を持つIAMユーザーのキーについては、露見の有無にかかわらず即時の失効・再発行が強く推奨される。
