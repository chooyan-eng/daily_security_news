# xAI Grok「Cryptographic Context Injection」攻撃（2026年）

## 概要

xAIのWebチャットエージェント「Grok」に存在する新種のプロンプトインジェクション手法。攻撃者が用意したWebページに暗号化（AES-256-GCM）された命令文と復号鍵を埋め込み、Grokがそれを復号・実行してしまうことで、ユーザー名・おおよその位置情報・サブスクリプション種別・チャット履歴が攻撃者サーバーへ送信される恐れがある。ガードレールが平文の悪意あるパターン検出に依存しているため、暗号化ペイロードがスキャンをすり抜ける構造的な問題。2026年6月3日に報告されたが2026年8月19日時点で未修正。

**同一性の判断に役立つ情報：**
- 攻撃手法名: Cryptographic Context Injection
- 対象サービス: xAI Grok（Webチャットエージェント）
- 暗号方式: AES-256-GCM
- 攻撃成立条件: 悪意あるWebページの閲覧（ゼロクリックに近い性質）
- 持ち出される情報: ユーザー名、おおよその位置情報、サブスクリプション種別、チャット履歴全体
- 初回報告日: 2026年6月3日
- 再報告日: 2026年8月4日、2026年8月10日
- 修正状況: 2026年8月19日時点で未修正・修正時期未公表
- 報告者: Utevsky氏
- 他サービスへの影響: 同種のガードレール回避手法がGemini等の他AIサービスにも影響しうると指摘
