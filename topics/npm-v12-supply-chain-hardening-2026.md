# npm v12 サプライチェーン対策強化（2026年）

## 概要

npmが2026年7月にリリース予定のv12で導入するサプライチェーン攻撃対策。依存パッケージのインストールスクリプト実行、Git依存関係の解決、リモートURL経由の依存取得をすべてデフォルトで無効化し、明示的なオプトインへ転換する破壊的変更。2025年に約45.5万件の悪性パッケージが公開されるなど過去最悪となったnpmサプライチェーン攻撃（axios、node-ipc、Red Hat npm名前空間侵害「Miasma」等）への対応。

**同一性の判断に役立つ情報：**
- 対象: npm v12（2026年7月リリース予定）
- 変更内容: (1) install系スクリプトの自動実行をデフォルトブロック（`--allow-scripts`） (2) Git依存関係解決をデフォルトブロック（`--allow-git`） (3) リモートURL経由の依存取得をデフォルトブロック（`--allow-remote`）
- 前段階の警告表示: npm 11.16.0以降
