# 1Password 従業員GitHubアカウント侵害・顧客メタデータ流出（2026年11月）

## 概要

1Passwordの従業員の業務用GitHubアカウントが侵害され、バックエンドサービスに不正コードをプッシュされて一部顧客の氏名・メールアドレス・アカウントメタデータ、招待／リカバリリンクのトークンの一部が流出した事案。非公開ソースコードの複製とCI/CDへのアクセスも確認。Vault内容・アカウントパスワード・Secret Keyは影響なしとされる。

**同一性の判断に役立つ情報：**
- 検知・調査開始: 2026-11-19／公表: 2026-11-25頃
- 侵入口: 従業員のGitHubアカウント（侵害手法は非公表）
- 影響顧客数: 非公表
