# Injective SDK npmサプライチェーン攻撃（2026年7月）

## 概要

ブロックチェーン基盤InjectiveのTypeScript SDK（npm）が、既存コントリビューターのGitHubアカウント侵害を通じてサプライチェーン攻撃を受けた。悪意あるバージョン1.20.21がウォレット作成関数にコードを注入し、ニーモニックフレーズと秘密鍵を外部サーバーへ送信。18パッケージへ連鎖配信されたが、検知から1時間未満で撤回。

**同一性の判断に役立つ情報：**
- 対象: Injective Labs TypeScript SDK（npm）
- 悪意あるバージョン: 1.20.21
- 攻撃経路: 既存コントリビューターのGitHubアカウント侵害
- 窃取対象: ウォレットのニーモニックフレーズ・秘密鍵
- 影響パッケージ数: 18パッケージ（同一バージョン番号で連鎖公開）
- SDKの週間ダウンロード数: 約5万
- 依存パッケージ数: 87
- 発覚から撤回まで: 1時間未満
- 修正済みバージョン: 1.20.23以降
- 発見: Socket
