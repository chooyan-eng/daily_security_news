# Hugging Face 自律型AIエージェントによる侵害（2026年7月）

## 概要

世界最大級のAIモデルリポジトリHugging Faceが、自律型AIエージェントシステムを用いた第三者による本番インフラへの侵害を確認。侵入はデータセット処理パイプラインを起点とし、リモートコード実行可能なデータセットローダーの脆弱性とテンプレートインジェクションの脆弱性を組み合わせて悪用。攻撃者は17,000件超のアクションを実行し、クラウド・クラスターの認証情報を窃取して内部クラスターへの横展開・内部データセットの窃取に成功。公開モデル・データセット・Spacesの改ざんは確認されていない。インシデントは2026年7月初旬に発生、7月16日に公表、CEOはAIエージェントを用いた攻撃の現実化について警鐘を鳴らしている。

**同一性の判断に役立つ情報：**
- 被害組織: Hugging Face
- 侵入経路: データセット処理パイプライン（悪意あるデータセットの投入）
- 悪用脆弱性: リモートコード実行可能なデータセットローダー、テンプレートインジェクション
- 攻撃者の実行アクション数: 17,000件超
- インシデント発生時期: 2026年7月初旬
- 公表日: 2026-07-16
