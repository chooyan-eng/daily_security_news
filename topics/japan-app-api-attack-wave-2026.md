# 国内で相次ぐアプリ・API経由の不正アクセスと情報漏えい（2026年10月）

## 概要

2026年9〜10月、国内でアプリ会員基盤・APIを狙った不正アクセスによる情報漏えいが相次いでいる。JPCERT/CC（JPCERT-AT-2026-0030、10/8）は既知脆弱性探索・API経由の不正操作・Metabase（CVE-2026-72898）悪用の3類型を挙げ、NICT（10/13）は公開アプリ解析からのサーバ攻撃「A2B攻撃」を注意喚起した。関連事案: セイコーマート、焼肉きんぐ、ローソン等。
