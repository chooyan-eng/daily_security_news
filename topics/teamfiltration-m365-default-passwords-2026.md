# TeamFiltration悪用「UNK_CondorFiltration」M365パスワードスプレーキャンペーン（2026年）

## 概要

Proofpointが追跡する脅威クラスター「UNK_CondorFiltration」による、攻撃的セキュリティツール「TeamFiltration」を悪用したMicrosoft 365パスワードスプレーキャンペーン。2026年7月末〜8月に3波にわたり28テナント・約5,700アカウントを標的とし、ローテーションされない既定パスワード・MFA未設定のサービスアカウント7件を侵害。標的の大半はチリの小売・金融機関。

**同一性の判断に役立つ情報：**
- 脅威クラスター名: UNK_CondorFiltration（Proofpoint命名）
- 悪用ツール: TeamFiltration（Entra ID列挙・スプレー・データ持ち出し・バックドア設置用の正規攻撃的セキュリティフレームワーク）
- 活動期間: 2026年7月末〜8月（3波）
- 規模: 28 Microsoft 365テナント、約5,700アカウントへの認証試行、侵害成功7アカウント（すべて非対人のサービス/機能アカウント）
- 攻撃元: 1,487個のユニークAWS EC2送信元IPアドレス
- 主な標的: チリの小売業者（観測イベントの78.3%）、金融機関
- 手口: ローテーションされない既定パスワードへのスプレー攻撃、MFA未設定アカウントの悪用
