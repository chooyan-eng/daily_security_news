# Node.js 2026年7月定例セキュリティリリース

## 概要

Node.jsプロジェクトが2026年7月27日に公開した定例セキュリティリリース。現在アクティブな22.x／24.x／26.xの全リリースラインが対象で、最大深刻度はHIGH。Next.js等を含むJavaScriptエコシステム全体の協調的なセキュリティアップデート週間の一部として実施された。詳細なCVE番号・脆弱性内容はリリース公開に合わせて順次開示される。

**同一性の判断に役立つ情報：**
- 対象: Node.js 22.x／24.x／26.x（全アクティブリリースライン）
- リリース日: 2026年7月27日（月）
- 最大深刻度: HIGH
- 位置づけ: JavaScriptエコシステム全体の協調的パッチ週間の一部
