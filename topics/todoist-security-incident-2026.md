# Todoist セキュリティインシデント（2026年11月）

## 概要

Todoistのバージョン管理システムに紐づく認証情報が窃取され、3リポジトリの自動ワークフローを改変されて追加の認証情報を取得、本番環境からユーザー情報が持ち出された事案。

**同一性の判断に役立つ情報：**
- 発生: 2026-11-22〜23／通知開始: 2026-11-24
- 約6%のユーザー: メールアドレス、アカウント作成日、旧式ソルト付きSHA-1パスワードハッシュ
- 約0.003%: Todoist APIトークン・Slack連携トークン／約0.001%: Outlookアドインのデータ
