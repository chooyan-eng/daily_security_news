# Chrome定例セキュリティアップデート（2026年7月）

## 概要

Googleが2026年7月21日に公開したChrome安定版（150.0.7871.181/.182）向けセキュリティアップデート。WebAudio・ANGLE・V8・Skia・拡張機能・GPUプロセスなどに影響する高深刻度（High）のメモリ安全性脆弱性12件（CVE-2026-16413〜16424）を修正。うち2件（CVE-2026-16420、CVE-2026-16421）は自律型AIセキュリティ研究システム「XBOW」が発見。野生での悪用は確認されていない。

**同一性の判断に役立つ情報：**
- 修正バージョン: Chrome 150.0.7871.181/.182（Windows/Mac）、150.0.7871.181（Linux）
- CVE範囲: CVE-2026-16413〜CVE-2026-16424（12件、いずれもHigh評価）
- AI発見分: CVE-2026-16420、CVE-2026-16421（XBOWが発見）
- 悪用状況: 野生での悪用・PoC公開は未確認
- 公開日: 2026-07-21
