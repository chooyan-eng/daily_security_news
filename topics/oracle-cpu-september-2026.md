# Oracle Critical Patch Update 2026年9月

## 概要

Oracleが2026年9月15日に公開した四半期定例セキュリティパッチ「Critical Patch Update（CPU）」。673件の脆弱性修正を含み、他の修正に同梱される形で解消された130件超を合わせると実質800件超に及ぶ、過去最大級の規模となった。17製品ファミリーにまたがり、100件超がCritical、240件超が認証不要でリモートから悪用可能。

**同一性の判断に役立つ情報：**
- リリース日: 2026年9月15日
- 修正件数: 673件（公式パッチ）、実質800件超（同梱修正含む）
- 深刻度内訳: Critical 104件（15.5%）、Important 503件（74.7%）、Medium 59件
- 主要影響製品: Oracle E-Business Suite（159件、全体の約24%）、Oracle Fusion Middleware（153件、うちCritical 67件）
- 特徴: 100件超がCVSS Critical、240件超が認証不要でリモート悪用可能
