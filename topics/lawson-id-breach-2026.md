# ローソンID・アプリ予約 不正アクセス事案（2026年10月）

## 概要

ローソンは2026年10月8日、「ローソンID」と「ローソンアプリ予約」への不正アクセスで個人情報が漏えいしたと発表した。ローソンIDは215万5,345件、アプリ予約は26件が対象で、予約ではカード番号の一部も含まれる。

**同一性の判断に役立つ情報：**
- 侵入: ID 9/12-14、予約 9/17
- 原因: 本人表示用セキュリティ機構への不正アクセス
