# SolarWinds Web Help Desk SAML認証バイパス（CVE-2026-28323）

## 概要

SolarWinds Web Help Desk の SAML 2.0 SSO実装における認証レスポンス検証不備により、攻撃者が正規の認証情報なしに正規ユーザーへなりすませる重大な認証バイパス脆弱性。研究者Dhabaleshwar Das氏が発見。

**同一性の判断に役立つ情報：**
- CVE: CVE-2026-28323
- CVSS: 9.8
- 対象製品: SolarWinds Web Help Desk（SAML SSO利用時）
- 修正バージョン: 2026.2.1（2026年7月30日リリース）
- 発見者: Dhabaleshwar Das
