# 「ASCIIスマグリング」不可視Unicode悪用フィッシングキャンペーン（2026年）

## 概要

Microsoftが検知した、AIプロンプトインジェクション研究に由来する不可視Unicodeタグ文字（ASCIIスマグリング）を悪用し、金融関連の誘導ワードを分割・隠蔽してメールフィルタを回避するフィッシングキャンペーン。2026年2月頃から観測され、平日最大237万通のメールが送信された。マーケティング自動化プラットフォーム「ActiveCampaign」を悪用しSBA融資申請者を狙う別キャンペーンとの関連が指摘されている。

**同一性の判断に役立つ情報：**
- 手法名: ASCIIスマグリング（不可視Unicodeタグ文字によるテキスト隠蔽）
- 検知元: Microsoft Defender
- 観測開始: 2026年2月頃
- ピーク時のメール量: 1日最大237万通（平常時は約21,000通）
- 関連キャンペーン: ActiveCampaign悪用によるSBA融資申請者標的フィッシング
- 検知率: Microsoft Defenderの他保護機構により99%超をブロック
- 公表日: 2026年9月4日
