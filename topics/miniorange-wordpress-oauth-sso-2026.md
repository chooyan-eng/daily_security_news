# miniOrange WordPress OAuth SSOプラグイン認証バイパス（CVE-2026-57807）

## 概要

WordPress用「miniOrange OAuth Single Sign-On」プラグインのパスワードリカバリー機構の欠陥に起因する認証バイパス脆弱性CVE-2026-57807（CVSS9.8）。認証・事前アクセス・ユーザー操作不要で悪用可能。バージョン38.5.8以下が影響を受ける。Patchstackが2026年7月9日開示、記事執筆時点で公式パッチ未提供、Patchstackが仮想パッチで対応。

**同一性の判断に役立つ情報：**
- CVE: CVE-2026-57807（CVSS9.8、CWE-288 認証バイパス）
- 対象製品: WordPress プラグイン「miniOrange OAuth Single Sign-On」バージョン38.5.8以下
- 開示日: 2026年7月9日（Patchstack）
- 公式パッチ: 記事執筆時点で未提供（Patchstackが仮想パッチ提供）
