# Roundcube Webmail セキュリティアップデート（2026年9月）

## 概要

オープンソースWebメールクライアントRoundcubeの2026年9月定例セキュリティアップデート。1.6 LTS系列（1.6.19）と1.7系列（1.7.4）で合計12件の脆弱性を修正。TNEF MIMEタグ注入によるゼロクリック蓄積型XSS、3種類のメールヘッダーインジェクション、連絡先グループの権限不備によるユーザー間アクセス、リモートコンテンツ制限バイパス、SSRFフィルタ回避を含む。

**同一性の判断に役立つ情報：**
- 対象製品: Roundcube Webmail
- 修正バージョン: 1.6.19（LTS系列）、1.7.4（1.7系列）
- リリース日: 2026年9月6日
- 修正件数: 12件
- 主な脆弱性: TNEF MIMEタグ注入によるゼロクリック蓄積型XSS（添付ファイルURL経由）、メールヘッダーインジェクション3種（件名の裸CR文字／宛先表示名のC言語スタイル\rエスケープ／アイデンティティ組織名フィールド）、連絡先グループメンバーシップ操作でのユーザー間不正アクセス、リモートコンテンツ読み込み制限バイパス、SSRFフィルタ回避
