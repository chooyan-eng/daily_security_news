# アンビションDXホールディングス ファイルサーバー不正アクセス事案（2026年8月）

## 概要

株式会社アンビションDXホールディングスが2026年8月6日未明に社内ファイルサーバーでアクセス障害を検知し、調査の結果ログの消失を確認した事案。8月6日の第1報、8月7日の第2報を経て、8月28日公表の第3報で一部の情報資産における情報漏えいが確認された。漏えい情報の具体的項目・侵入経路の詳細は本稿執筆時点で未公表。

**同一性の判断に役立つ情報：**
- 被害組織: 株式会社アンビションDXホールディングス
- 対象システム: 社内ネットワークのファイルサーバー
- 発生検知日: 2026年8月6日未明
- 経過: 第1報（8月6日、アクセス障害・ログ消失確認）→第2報（8月7日）→第3報（8月28日、情報漏えい確認）
- 特徴: ログ消失により侵入経路・活動範囲の特定が難航
