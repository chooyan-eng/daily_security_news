# Node.js 2026年7月セキュリティリリース

## 概要

Node.js プロジェクトが2026年7月29日（インフラ問題により延期の上）に公開した緊急セキュリティリリース。v22.23.2・v24.18.1・v26.5.1で、HTTP/2ルーティング、Permission Model（サンドボックス回避）、ヒープメモリ管理などに関わる高深刻度脆弱性を含む10件のCVEを修正。バンドルのUndici・llhttpも更新。

**同一性の判断に役立つ情報：**
- リリースバージョン: v22.23.2 / v24.18.1 / v26.5.1
- 修正件数: CVE 10件（うち高深刻度3件）
- 公表日: 2026-07-29
- 対象領域: HTTP/2、Permission Model、ヒープメモリ、HTTPS接続再利用、DNS解決、SQLite、Zlib、HTTPパーサー
