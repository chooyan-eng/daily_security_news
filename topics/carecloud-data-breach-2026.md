# CareCloud データ侵害（2026年）

## 概要

米ニュージャージー州の電子カルテ（EHR）・医療請求SaaS事業者 CareCloud のクラウド環境（AWS）が2026年3月に侵害され、患者の個人情報・医療情報・金融情報が持ち出された事案。当初の届出では約35万人とされていた影響人数が、2026年8月中旬の届出更新により370万人超へ大幅に上方修正され、2026年の医療データ侵害としては最大級の規模となった。全米数万の医療機関に対してサービスを提供するマルチテナント型SaaSであり、1つのクラウド環境の侵害が多数の委託元へ波及した構図である。

**同一性の判断に役立つ情報：**
- 被害組織: CareCloud（米ニュージャージー州、電子カルテ／医療請求SaaS事業者）
- 侵害された環境: 同社の AWS 環境
- 不正アクセス期間: 2026年3月10日〜3月16日（6日間）
- 検知: 2026年3月16日（ネットワーク障害として検知）
- 影響範囲評価完了: 2026年6月24日
- 影響人数の推移: 当初届出 約345,000〜350,000人 → HHS届出 3,371,508人 → 370万人超へ修正
- HHS OCR ポータル届出: 2026年8月17日、翌18日に更新
- 流出情報: 氏名、住所、生年月日、社会保障番号（SSN）、運転免許証番号、健康保険被保険者ID・保険会社名・証券番号・グループ番号、医療情報、クレジット／デビットカード情報
- 犯行声明: 公に犯行声明を出したグループは確認されていない（3月16日以降の継続的な不正活動も未確認）
