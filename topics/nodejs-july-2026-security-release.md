# Node.js 2026年7月セキュリティリリース

## 概要

Node.jsの稼働中全ブランチ（22.x/24.x/26.x）を対象とした2026年7月のセキュリティリリース。Permission Modelバイパス、HTTPS TLSセッション再利用問題、node:sqliteの不具合、HTTP/2ルーティング等、合計11件（10 CVE）の脆弱性を修正。

**同一性の判断に役立つ情報：**
- リリース日: 2026年7月29日（水）
- 修正バージョン: v22.23.2 / v24.18.1 / v26.5.1
- 修正件数: 11件（10 CVE、うちHigh 3件）
- 主な対象領域: HTTP/2、Permission Model、HTTPS、DNS、SQLite、Zlib、HTTPパーサー
