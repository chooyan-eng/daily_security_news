# DHS Homeland Security Information Network（HSIN）侵害（2026年5-7月）

## 概要

米国土安全保障省（DHS）は、連邦・州・地方自治体・業界・海外パートナー間で機微な非機密情報を共有するプラットフォーム「Homeland Security Information Network（HSIN）」への侵入を確認したと公表した。侵入の痕跡は2026年5月15日〜24日にかけてFEMAのアナリストにより一度検知されたが誤検知と判断され、5月25日〜6月3日の再度の不審な挙動も同様に見過ごされた。攻撃者は数週間にわたり検知を逃れ、最終的に認証情報ファイルを窃取した。攻撃者の身元は7月時点で特定されていない。

**同一性の判断に役立つ情報：**
- 対象システム: Homeland Security Information Network（HSIN） - 連邦・州・地方・業界・海外パートナー向け非機密情報共有プラットフォーム
- 初回検知（誤検知と判断）: 2026年5月15日〜24日
- 再検知（誤検知と判断）: 2026年5月25日〜6月3日
- 侵害確認・公表: 2026年7月13日
- 窃取された情報: 認証情報ファイル
- 攻撃者の帰属: 未特定（調査継続中）
