# DHS 情報共有プラットフォーム「HSIN」侵害（2026年）

## 概要

米国土安全保障省（DHS）が運営する情報共有プラットフォーム「Homeland Security Information Network（HSIN）」への不正侵入事案。2026年5月下旬〜6月上旬に侵入が発生したとみられ、HSINサーバーおよびコラボレーション用SharePointシステムが標的にされた。脅威アクターの帰属や窃取情報の有無は調査中。ワールドカップ2026の警備調整にも利用されるシステムであることから国家安全保障上の懸念が指摘されている。

**同一性の判断に役立つ情報：**
- 被害システム: Homeland Security Information Network（HSIN）
- 運営組織: 米国土安全保障省（DHS）
- 侵入推定時期: 2026年5月下旬〜6月上旬
- 標的: HSINサーバー、コラボレーション用SharePointシステム
- 帰属: 未確定（調査中）
- 特記事項: ワールドカップ2026警備調整にも利用されるシステム
- 被害組織: 米国土安全保障省（DHS）
- 標的システム: HSIN（Homeland Security Information Network）、協業用SharePointシステム
- 侵入時期: 2026年5月末〜6月上旬
- 公表日: 2026年7月1日
- 影響範囲: 非機密階層のセキュリティ計画・イベント調整情報（FIFAワールドカップ関連含む）
- 機密系統への影響: なし（DHS発表）
- 攻撃者の帰属: 未確定
- 調査状況: フォレンジック調査継続中、データ持ち出しの有無は調査中
- 対象システム: HSIN（Homeland Security Information Network）
- 侵入時期: 2026年5月下旬〜6月上旬（推定）
- 公表時期: 2026年7月2〜3日
- 攻撃者: 未特定（国家関与の有無も不明）
- 関連システム: SharePointベースのコラボレーションシステム
- 侵害システム: HSIN（Homeland Security Information Network）、連携用SharePoint
- 発生時期: 2026年5月下旬〜6月上旬（推定）
- 攻撃者: 未特定・未帰属
- 公表: 2026-06-30〜07-01
