# 米国土安全保障省 情報共有基盤HSIN不正侵入（2026年）

## 概要

米国土安全保障省（DHS）が運用する連邦・州・民間機関間の脅威情報共有基盤HSIN（Homeland Security Information Network）および協業用SharePointシステムが、2026年5月末〜6月上旬にかけて不正アクセスを受けた事案。FIFAワールドカップ等の大型イベント警備調整に関する非機密情報が、数週間気づかれないまま外部から閲覧可能な状態にあった。機密系統への影響はないとされる。7月1日に公表。攻撃者の身元は未確定。

**同一性の判断に役立つ情報：**
- 被害組織: 米国土安全保障省（DHS）
- 標的システム: HSIN（Homeland Security Information Network）、協業用SharePointシステム
- 侵入時期: 2026年5月末〜6月上旬
- 公表日: 2026年7月1日
- 影響範囲: 非機密階層のセキュリティ計画・イベント調整情報（FIFAワールドカップ関連含む）
- 機密系統への影響: なし（DHS発表）
- 攻撃者の帰属: 未確定
- 調査状況: フォレンジック調査継続中、データ持ち出しの有無は調査中
