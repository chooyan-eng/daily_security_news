# 米国土安全保障省 HSIN 不正侵入事件（2026年）

## 概要

米国土安全保障省（DHS）が運営する情報共有プラットフォーム「HSIN（Homeland Security Information Network）」への不正侵入が確認された事案。2026年5月下旬〜6月上旬に侵入が発生したとみられ、HSINに紐づくSharePointベースのコラボレーションシステムも影響を受けた可能性がある。HSINは2026年米国開催ワールドカップの警備調整にも使用されており、影響範囲が注視されている。

**同一性の判断に役立つ情報：**
- 被害組織: 米国土安全保障省（DHS）
- 対象システム: HSIN（Homeland Security Information Network）
- 侵入時期: 2026年5月下旬〜6月上旬（推定）
- 公表時期: 2026年7月2〜3日
- 攻撃者: 未特定（国家関与の有無も不明）
- 関連システム: SharePointベースのコラボレーションシステム
- 侵害システム: HSIN（Homeland Security Information Network）、連携用SharePoint
- 発生時期: 2026年5月下旬〜6月上旬（推定）
- 攻撃者: 未特定・未帰属
- 公表: 2026-06-30〜07-01
