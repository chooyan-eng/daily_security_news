# DHS Homeland Security Information Network（HSIN）侵害（2026年5-7月）

## 概要

米国土安全保障省（DHS）は、連邦・州・地方自治体・業界・海外パートナー間で機微な非機密情報を共有するプラットフォーム「Homeland Security Information Network（HSIN）」への侵入を確認したと公表した。侵入の痕跡は2026年5月15日〜24日にかけてFEMAのアナリストにより一度検知されたが誤検知と判断され、5月25日〜6月3日の再度の不審な挙動も同様に見過ごされた。攻撃者は数週間にわたり検知を逃れ、最終的に認証情報ファイルを窃取した。攻撃者の身元は7月時点で特定されていない。

**同一性の判断に役立つ情報：**
- 対象システム: Homeland Security Information Network（HSIN） - 連邦・州・地方・業界・海外パートナー向け非機密情報共有プラットフォーム
- 初回検知（誤検知と判断）: 2026年5月15日〜24日
- 再検知（誤検知と判断）: 2026年5月25日〜6月3日
- 侵害確認・公表: 2026年7月13日
- 窃取された情報: 認証情報ファイル
- 攻撃者の帰属: 未特定（調査継続中）
- 被害システム: Homeland Security Information Network（HSIN）
- 運営組織: 米国土安全保障省（DHS）
- 侵入推定時期: 2026年5月下旬〜6月上旬
- 標的: HSINサーバー、コラボレーション用SharePointシステム
- 帰属: 未確定（調査中）
- 特記事項: ワールドカップ2026警備調整にも利用されるシステム
- 被害組織: 米国土安全保障省（DHS）
- 標的システム: HSIN（Homeland Security Information Network）、協業用SharePointシステム
- 侵入時期: 2026年5月末〜6月上旬
- 公表日: 2026年7月1日
- 影響範囲: 非機密階層のセキュリティ計画・イベント調整情報（FIFAワールドカップ関連含む）
- 機密系統への影響: なし（DHS発表）
- 攻撃者の帰属: 未確定
- 調査状況: フォレンジック調査継続中、データ持ち出しの有無は調査中
- 対象システム: HSIN（Homeland Security Information Network）
- 侵入時期: 2026年5月下旬〜6月上旬（推定）
- 公表時期: 2026年7月2〜3日
- 攻撃者: 未特定（国家関与の有無も不明）
- 関連システム: SharePointベースのコラボレーションシステム
- 侵害システム: HSIN（Homeland Security Information Network）、連携用SharePoint
- 発生時期: 2026年5月下旬〜6月上旬（推定）
- 攻撃者: 未特定・未帰属
- 公表: 2026-06-30〜07-01
