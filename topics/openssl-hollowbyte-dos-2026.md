# OpenSSL HollowByte メモリ枯渇 DoS 脆弱性（2026年）

## 概要

未認証の攻撃者がわずか11バイトの TLS ペイロードで OpenSSL サーバーのメモリを継続的に枯渇させられる DoS 脆弱性「HollowByte」。偽装した長さフィールドにより不当な事前メモリ確保（最大131KB）を発生させ、glibc アロケータの挙動と組み合わせて RSS を増大させ続け、最終的に OOM でサービス停止に至る。2026年6月に CVE 番号・アドバイザリなしで静かに修正されており、周知が遅れていた。

**同一性の判断に役立つ情報：**
- 脆弱性名: HollowByte
- 対象: OpenSSL（TLS ハンドシェイク処理）
- 修正版: OpenSSL 4.0.1（バックポート: 3.6.3 / 3.5.7 / 3.4.6 / 3.0.21）
- 攻撃手法: 11バイトの偽装ペイロードによる事前メモリ確保の悪用 + glibc アロケータのフラグメンテーション誘発
- 検証: Okta セキュリティチーム（NGINX 環境）
- 発見者: Okta Red Team
- 対象製品: OpenSSL（TLSハンドシェイク実装）
- 攻撃ペイロードサイズ: 11バイト
- CVE: 付与なし（サイレント修正）
- 修正バージョン: 4.0.1、3.6.3、3.5.7、3.4.6、3.0.21
