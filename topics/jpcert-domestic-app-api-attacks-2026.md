# 国内Webサービス・アプリを狙う相次ぐ不正アクセスとJPCERT/CC・内閣サイバー注意喚起（2026年9〜10月）

## 概要

2026年9月前後から国内でWebサービス・スマホアプリ・BIツールの個人情報漏えいが相次ぎ、JPCERT/CCが10月8日に注意喚起（JPCERT-AT-2026-0030）を公開、内閣サイバーも10月14日に注意喚起を出した。

**同一性の判断に役立つ情報：**
- 文書番号: JPCERT-AT-2026-0030（2026-10-08）
- 手口: 公開アプリ解析による内部API攻撃（権限変更・不正アカウント作成）／既知脆弱性・管理不備の探索／Metabase CVE-2026-72898（SQLi）悪用
- 対策: APIレート制限、全エンドポイントの認可、最小権限、APIトークン有効期限
