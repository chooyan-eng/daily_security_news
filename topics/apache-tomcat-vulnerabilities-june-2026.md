# Apache Tomcat 複数脆弱性（2026年6月）

## 概要

Apache Tomcatに報告された計6件の脆弱性。代表的なものはCVE-2026-55956（defaultサーブレットの認可バイパス）とCVE-2026-55955（リプレイ対策不備）で、一部はクリティカル評価。Apache Software Foundationが2026年6月29日付でアドバイザリを公開し、JPCERT/CCが7月1日付で注意喚起を行った。

**同一性の判断に役立つ情報：**
- 対象製品: Apache Tomcat
- 主なCVE: CVE-2026-55956（認可バイパス）、CVE-2026-55955（リプレイ対策不備）
- 脆弱性件数: 計6件
- アドバイザリ公開日: 2026年6月29日（Apache Software Foundation）
- JPCERT/CC注意喚起日: 2026年7月1日
