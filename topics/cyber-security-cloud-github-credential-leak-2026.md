# サイバーセキュリティクラウド GitHub認証情報流出事案（2026年11月）

## 概要

クラウド型WAF等を提供するサイバーセキュリティクラウドで、従業員が業務で使用していたGitHub認証情報1件が外部に流出し、これを用いたとみられる不審アクセスが確認された事案（確認日2026年11月5日、公表11月12日）。一部顧客の企業名・氏名・メールアドレス・通信関連情報が漏えいしたおそれ。サービス本体への不正アクセスは確認されていない。
