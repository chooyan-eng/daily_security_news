# 1Password 従業員GitHubアカウント侵害・バックエンド不正アクセス事案（2026年11月）

## 概要

1Passwordが2026年11月に公表したインシデント。11月19日に従業員の業務用GitHubアカウントに関連する不審な活動を検知。攻撃者はソースコードにアクセスし、CI/CDパイプラインを通じてバックエンドサービスに悪意あるコードを送り込み、一部ユーザーの管理系レコード（氏名、アカウント識別子、招待・プロビジョニング・アカウント回復用メールリンクのトークン等）を取得。保管庫（Vault）の内容や鍵は影響なしとされる。
