# TheHatman による Azure/Entra ID 認証情報侵害キャンペーン（2026年）

## 概要

「TheHatman」を名乗る脅威アクターが、侵害したMicrosoft Azure／Entra IDテナントから窃取した複数企業の従業員ディレクトリデータを地下フォーラムで販売している事案。窃取した正規企業認証情報を悪用してクラウドディレクトリサービスにアクセスしたとみられ、技術サービス・ホスピタリティ・通信・小売・物流分野の少なくとも9社のFortune 500クラス企業が対象に含まれる。侵入手口はパスワードスプレー攻撃およびMFA疲労攻撃（MFA fatigue）とされる。

**同一性の判断に役立つ情報：**
- 攻撃者名: TheHatman（自称）
- 対象: Microsoft Azure / Entra ID（旧Azure AD）テナント
- 手口: パスワードスプレー攻撃・MFA疲労攻撃で窃取した企業認証情報を用いたクラウドディレクトリへの不正アクセス、従業員名簿データの窃取・販売
- 確認日: 2026年8月17日〜（継続的に新規企業名を投稿中）
- 対象企業: マクドナルド、Gap Inc.、ボーダフォン、TCS、HCLテクノロジーズ、IHG、Kyndryl等、少なくとも9社
- 累計主張件数: 約364万件（2026年8月25日時点、マクドナルド分約170万件含む）
- 影響業種: 技術サービス、ホスピタリティ、通信、小売、物流（Fortune 500クラス9社以上）
- 備考: TCSは調査の結果、自社システム侵害の信頼できる証拠はなく情報は4年以上前のものと主張するなど、企業側の反論もあり被害の実態は係争中
