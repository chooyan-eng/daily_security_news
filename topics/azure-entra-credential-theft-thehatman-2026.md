# TheHatman による Azure/Entra ID 認証情報侵害キャンペーン（2026年）

## 概要

「TheHatman」を名乗る脅威アクターが、侵害したMicrosoft Azure／Entra IDテナントから窃取した複数企業の従業員ディレクトリデータを地下フォーラムで販売している事案。窃取した正規企業認証情報を悪用してクラウドディレクトリサービスにアクセスしたとみられ、技術サービス・ホスピタリティ・通信・小売・物流分野の少なくとも9社のFortune 500クラス企業が対象に含まれる。

**同一性の判断に役立つ情報：**
- 攻撃者名: TheHatman（自称）
- 対象: Microsoft Azure / Entra ID（旧Azure AD）テナント
- 手口: 窃取済み企業認証情報を用いたクラウドディレクトリへの不正アクセス、従業員名簿データの窃取・販売
- 確認日: 2026年8月17日
- 影響業種: 技術サービス、ホスピタリティ、通信、小売、物流（Fortune 500クラス9社以上）
