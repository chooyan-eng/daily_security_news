# Accenture データ侵害・ソースコード窃取主張（2026年7月）

## 概要

ハッカーフォーラム上で「888」を名乗る脅威アクターが、Accentureから35GBのデータ（Azureアクセスキー、設定ファイル、RSA/SSH鍵、ソースコード）を窃取したと主張し販売を持ちかけた事案。Accentureは「限定的な事案であり原因は是正済み」と侵害を確認。同攻撃者はDecathlon、Credit Suisse、Shell、Heineken、UNICEFへの侵害主張歴を持つ。

**同一性の判断に役立つ情報：**
- 被害組織: Accenture
- 攻撃者名: 「888」（PwnForums上のハンドル名）
- 主張データ量: 35GB
- 主張データ内容: Azureアクセスキー・トークン、設定ファイル、RSA/SSH鍵、ソースコード
- 攻撃者の過去の主張歴: Decathlon、Credit Suisse、Shell、Heineken、UNICEF
