# ShinyHunters による Oracle PeopleSoft 攻撃キャンペーン

## 概要

脅威アクター ShinyHunters（Mandiant は UNC6240 として追跡）が、Oracle PeopleSoft の未パッチゼロデイ脆弱性 CVE-2026-35273（CVSS 9.8）を悪用し、大学を中心とした100社以上の組織・300インスタンス超に侵入したキャンペーン。2026年5月27日〜6月9日にかけて活動が確認された。Oracle は6月10日にパッチを公開。2026年7月時点で被害組織への金銭恐喝連絡が本格化しつつあり、今後も被害組織名の公表が続く見込み。

**同一性の判断に役立つ情報：**
- CVE: CVE-2026-35273
- 脅威アクター: ShinyHunters / UNC6240（Scattered LAPSUS$ Hunters連合の一角）
- 対象製品: Oracle PeopleSoft Enterprise PeopleTools
- 攻撃期間: 2026-05-27〜2026-06-09
- 被害規模: 100組織・300インスタンス超（約68%が高等教育機関、大半が米国）
