# 公開AWSアクセスキー放置問題（Truffle Security調査、2026年）

## 概要

セキュリティ企業Truffle Securityが2022年8月〜2026年8月の間に公開Gitリポジトリ・Hugging Faceデータセット・Dockerイメージ・パッケージレジストリ・CI/CDログ等で発見したAWSアクセスキーを2026年8月10日に再検証し、10,616件中88%（約9,300件超）が依然として有効だったと報告した調査。

**同一性の判断に役立つ情報：**
- 調査実施企業: Truffle Security
- 再検証日: 2026年8月10日
- 検証対象総数: 10,616件のAWSキーペア
- 有効だった割合: 88%（約9,300件超）
- 企業紐づけ確認数: 817件（うちルートキー526件、AdministratorAccess権限IAMユーザー242件）
- キー経過年数の中央値: 約1,831日（約5年）、最古17.4年
- ローテーション実施率: 13.7%（398件）のみ
- 主な発見経路: Gitコミット履歴、Hugging Faceデータセット、Dockerイメージ、パッケージレジストリ、CI/CDログ
