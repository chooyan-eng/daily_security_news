# C2Looper GitHub悪用バックドア（2026年）

## 概要

Zscaler ThreatLabzが2026年7月に確認したRust製バックドア。ランサムウェア関連の脅威アクターとの関連が指摘されている。新バージョンv2では、従来のHTTPベースC2エンドポイントを廃止し、GitHubリポジトリを完全なコマンド＆コントロール基盤として利用する手法を採用した。

**同一性の判断に役立つ情報：**
- マルウェア名: C2Looper（v2）
- 実装言語: Rust
- 初確認: 2026年7月（Zscaler ThreatLabz）
- 感染経路: 複数段階の「ClickFix」型感染チェーン（低〜中確度）
- C2手法: GitHubリポジトリ経由（`cmd.json`／`result.json`／`beacon.json`によるタスク送受信）
- v2追加機能: 偵察情報収集、ドライブ列挙、シェルコードインジェクション、ファイル一覧取得
- 関連: ランサムウェア関連脅威アクターとの関連が指摘（低〜中確度）
