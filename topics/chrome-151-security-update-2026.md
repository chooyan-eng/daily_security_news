# Chrome 151 セキュリティアップデート（2026年7月）

## 概要

Google Chrome バージョン151で実施された大型セキュリティアップデート。Critical 7件（Use-After-Free 4件、信頼できない入力の検証不足2件、Updaterのレースコンディション1件）を含む合計370件の脆弱性を修正。現時点で野生での悪用報告はなく、Chrome V8ゼロデイシリーズ（別トピック）とは異なる通常のセキュリティメンテナンスとして実施。

**同一性の判断に役立つ情報：**
- バージョン: Chrome 151.0.7922.71/.72
- リリース日: 2026年7月29日
- 修正件数: 370件（Critical 7、High 71、Medium 170、Low 122）
- 悪用確認: なし（2026年に確認されたV8ゼロデイ悪用シリーズとは別件）
