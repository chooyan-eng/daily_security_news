# イノベーション GitHub認証情報漏えい・不正アクセス（2026年8月）

## 概要

「ITトレンド」等を運営する株式会社イノベーションにおいて、グループ内の開発・システム管理に用いるGitHubの認証情報が漏えいし、第三者による不正アクセスが発生した事案。ソースコード・リポジトリ内に含まれていた個人情報が流出した可能性がある。

**同一性の判断に役立つ情報：**
- 事業者: 株式会社イノベーション（「ITトレンド」等運営）
- 侵害経路: GitHub認証情報の漏えい
- 公表日: 2026年8月4日（速報）
- 漏えい規模: 最大約6万件（氏名・メールアドレス、一部電話番号）
- 対応: 認証情報無効化、アカウント遮断、ソースコード内認証キー・パスワードの無効化と再発行
