# Linuxカーネル複数脆弱性、CISA KEVカタログへ追加・実悪用確認（2026年9月）

## 概要

米CISAが2026年9月19日、Linuxカーネルの脆弱性3件（CVE-2025-39682、CVE-2026-53266、CVE-2025-39964）を実悪用確認としてKEVカタログへ追加。いずれもローカル権限を持つ攻撃者による権限昇格・DoS・データ破損につながる脆弱性。Red Hatは同日アドバイザリを更新し実悪用を認めた。連邦文民行政機関は2026年9月21日までの対応が求められる。

**同一性の判断に役立つ情報：**
- CVE: CVE-2025-39682（CVSS 9.8、TLS受信パスの例外条件不備）、CVE-2026-53266（CVSS 8.8、ebtables SNAT ARP書き換えパスの境界外書き込み）、CVE-2025-39964（CVSS 7.8、AF_ALGソケットの競合状態）
- 脆弱性種別: いずれもローカル権限昇格・DoS・データ完全性問題（ローカル攻撃者前提）
- KEV追加日: 2026年9月19日
- Red Hatアドバイザリ更新: 2026年9月19日 2:00 UTC
- 対応期限: 連邦文民行政機関（FCEB）は2026年9月21日まで（BOD 26-04に基づく）
