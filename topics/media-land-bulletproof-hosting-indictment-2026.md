# Media Land / ML.Cloud バレットプルーフホスティング起訴（2026年7月）

## 概要

米オハイオ州北部地区連邦地検が、サンクトペテルブルクを拠点とするバレットプルーフホスティング業者Media Land LLC・ML.Cloud LLCの運営者3名のロシア国籍者を、コンピュータ詐欺・電信詐欺・マネーロンダリングの共謀容疑で起訴。両社のインフラはLockBit・BlackSuit・Playなど複数のランサムウェアグループに悪用され、米国内被害者に総額6200万ドル以上の損失をもたらしたとされる。

**同一性の判断に役立つ情報：**
- 被告: Alexander Alexandrovich Volosovik、Kirill Andreevich Zatolokin、Yulia Vladimirovna Pankova
- 関連企業: Media Land, LLC / ML.Cloud, LLC（サンクトペテルブルク拠点）
- 起訴日: 2026年7月15日発表（起訴状自体は2024年12月付）
- 悪用したランサムウェアグループ: LockBit、BlackSuit、Playほか
- 被害総額: 6200万ドル以上（被害者44件）
