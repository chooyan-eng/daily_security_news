# WP2Shell WordPress コア RCE チェーン（2026年7月）

## 概要

WordPressコアの2脆弱性（CVE-2026-63030：REST APIバッチルート混同、CVE-2026-60137：SQLインジェクション）を連鎖させ、未認証の匿名リクエストのみでデフォルト設定のWordPressサイトを完全に乗っ取れる攻撃チェーン「WP2Shell」。ログインもプラグインインストールも不要。WordPress 6.9.0〜6.9.4および7.0.0〜7.0.1が影響を受ける。2026年7月20日、セキュリティ企業Coalitionがハニーポット上での実悪用を観測。WordPressは6.9.5・7.0.2をリリースし、影響の大きさから自動更新システムによる強制アップデートを実施。

**同一性の判断に役立つ情報：**
- 総称: WP2Shell
- CVE: CVE-2026-63030（REST APIバッチルート混同）、CVE-2026-60137（SQLインジェクション）
- 対象製品: WordPress コア（プラグイン不問）
- 影響バージョン: 6.9.0〜6.9.4、7.0.0〜7.0.1
- 修正バージョン: 6.9.5、7.0.2
- 実悪用観測日: 2026-07-20（Coalition）
