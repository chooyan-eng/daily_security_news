# 1Password GitHubアカウント侵害・顧客データ流出（2026年11月）

## 概要

パスワードマネージャー1Passwordが、従業員の企業GitHubアカウントを乗っ取られ、バックエンドサービスに悪意あるコードをプッシュされて顧客の管理用データ（氏名・メール・アカウント/ユーザー識別子・サインイン日時・SRPパラメータ等）を窃取された事案。非公開リポジトリのソースコードも複製され、CI/CDにもアクセスされた。Vaultの内容・鍵は影響なし。2026年11月19日に調査開始、11月25日公表。

**同一性の判断に役立つ情報：**
- 対象: 1Password（AgileBits）
- 初期侵入: 従業員の企業GitHubアカウント侵害 → バックエンドへの悪性コード投入（CI/CD経由）
- 調査開始: 2026-11-19 / 公表: 2026-11-25
- 流出: 氏名、サインイン用メール、アカウント/ユーザーID、サインイン日時、SRPパラメータ、招待・プロビジョニング・アカウント回復メール内の一部トークン、ソースコード
- 影響なし: Vault内容、アカウント回復キー、暗号鍵
