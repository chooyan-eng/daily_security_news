# Linuxカーネル 実悪用脆弱性のKEVカタログ追加（2026年9月）

## 概要

米CISAが、実際の悪用が確認されたLinuxカーネルの脆弱性3件（CVE-2025-39682、CVE-2026-53266、CVE-2025-39964）を既知の悪用脆弱性（KEV）カタログに追加した事案。連邦政府機関には2026年9月21日までの対応期限が設定された。

**同一性の判断に役立つ情報：**
- 発表元: 米CISA（KEVカタログ追加）、Red Hat（アドバイザリ更新）
- 対象CVE: CVE-2025-39682（CVSS 9.8、TLS受信パス）、CVE-2026-53266（CVSS 8.8、ebtables SNAT ARP書き換え）、CVE-2025-39964（CVSS 7.8、AF_ALGソケット競合状態）
- KEV追加日: 2026年9月19日
- 連邦機関対応期限: 2026年9月21日
