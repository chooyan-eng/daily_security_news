# Alby Hub 重大脆弱性 インターネット公開ウォレット乗っ取り（2026年）

## 概要

ビットコインLightningネットワーク向けセルフホスト型ウォレット管理ソフト「Alby Hub」の旧バージョン（v1.7.0〜v1.18.5）に存在する重大脆弱性。管理APIをインターネットに公開した状態で運用している場合、攻撃者が不正アクセスによりウォレットから資金を送出できるおそれがある。Alby社のクラウド版「Alby Cloud Hub」は影響を受けない。

**同一性の判断に役立つ情報：**
- 対象製品: Alby Hub（セルフホスト型ビットコインLightningウォレット）
- 影響バージョン: v1.7.0〜v1.18.5（2025年8月以前リリース）
- 修正済みバージョン: v1.19.0以降（2025年8月29日リリース）、最新推奨版はv1.24.0
- 前提条件: 管理APIがパブリックネットワークからアクセス可能な状態であること
- 影響: 不正アクセスによる保管資金の窃取
- 確認された被害: 1件（Alby社発表時点）
- 技術詳細: 未公開（責任ある開示方針のため後日公開予定）
