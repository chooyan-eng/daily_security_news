# 新型フィッシングキット「N0va」デバイスコード／AiTM認証悪用キャンペーン（2026年9月）

## 概要

北米・欧州の政府・技術・コンサルティング・医療等の組織を標的とする新型フィッシングキット「N0va」。Microsoft Teams・SharePoint・OneDrive・DocuSign・Google Drive・Dropbox・Zoom・Adobe Signなど日常業務ツールを装う誘導文言を用い、Microsoft正規のサインインインフラを介したデバイスコード／AiTM型認証フローを悪用して有効なアクセス・リフレッシュトークンを窃取する。

**同一性の判断に役立つ情報：**
- キャンペーン名: N0va（Phishkit）
- 標的地域・業種: 北米・欧州の政府、技術、コンサルティング、医療等
- 手口: 業務ツール（Teams/SharePoint/OneDrive/DocuSign/Google Drive/Dropbox/Zoom/Adobe Sign）を偽装、Microsoft正規認証フローを悪用したデバイスコード／AiTMフィッシング
- 被害内容: 正規の有効なアクセス・リフレッシュトークン窃取によるアカウント乗っ取り（マルウェア不使用）
- 攻撃インフラ: 侵害された正規サイト、Cloudflare Workers、Linode Object Storageに分散
- 報道日: 2026年9月16日
