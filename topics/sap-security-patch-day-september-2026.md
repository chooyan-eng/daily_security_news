# SAP 2026年9月セキュリティパッチデー

## 概要

SAPが2026年9月8日に公開した月例セキュリティパッチデー。新規19件・更新1件の計20件のセキュリティノートが公開され、最も深刻なCVE-2026-44756（SAP Extended Passport Processingのメモリ破損、CVSS 10.0）を含む。SAP NetWeaver、S/4HANA、Integration Suite、Commerce Cloud等の主要製品が対象。

**同一性の判断に役立つ情報：**
- 公開日: 2026年9月8日
- 修正件数: 新規19件＋更新1件＝計20件
- 最重要脆弱性: CVE-2026-44756（SAP Extended Passport Processing、メモリ破損、CVSS 10.0）
- 対象製品: SAP NetWeaver、SAP Extended Passport Processing、SAP Cloud Application Programming Model、SAP S/4HANA、SAP Integration Suite、SAP Commerce Cloud等
