# ガンダムベース会員情報漏えい（メール配信委託先ユミルリンク経由、2026年10月）

## 概要

バンダイナムコエンターテインメントとBANDAI SPIRITSが2026年10月27日に発表した、「THE GUNDAM BASE MEMBERS」登録のメールアドレス等34万6247件の漏えい事案。バンダイナムコIDのメール配信委託先ユミルリンクへの不正アクセスが原因。氏名・住所・購入履歴・パスワード・カード情報は対象外とされる。

**同一性の判断に役立つ情報：**
- 対象: THE GUNDAM BASE MEMBERS（バンダイナムコID）
- 件数: 346,247件（メールアドレス＋内部識別子）
- 原因: 委託先ユミルリンクへの不正アクセス
