# METR APIキー窃取・AIクレジット不正消費事案（2026年）

## 概要

AIモデル安全性評価団体METRが、研究者の公開EC2インスタンスの設定不備（フェイルオープンバグ）を突かれてモデル推論用APIキーを窃取された事案。攻撃者は約3週間気づかれずに時価60万ドル相当のAIクレジットを消費した。METRは2026年5月にも別の探索的攻撃キャンペーンを受けていたことを公表している。

**同一性の判断に役立つ情報：**
- 被害組織: METR（AIモデル安全性評価の非営利団体）
- 原因: 研究者の公開EC2インスタンスにおける「フェイルオープン」バグ（認証機能の意図せぬ無効化）
- 攻撃発生: 2026年3月
- 被害額: 約3週間で時価60万ドル相当のAIクレジット消費（無償供与クレジットのため直接的金銭損害ではない）
- 攻撃者の探索手法: 証明書透明性（CT）ログからLLM関連の高シグナル語を含む新規サイトを探索
- 関連事案: 2026年5月に別途、公開インフラへの探索的攻撃キャンペーンを確認・公表
