# n8n サンドボックスエスケープによるOSコマンド実行（2026年7月）

## 概要

ワークフロー自動化基盤「n8n」の式（Expression）評価用サンドボックスをエスケープし、ワークフロー編集権限を持つ認証済みユーザーがホストOS上で任意コマンドを実行できる脆弱性。2月に修正されたCVE-2026-27577の残存バイパスとして発見された。

**同一性の判断に役立つ情報：**
- 識別子: GHSA-gv7g-jm28-cr3m（CVE番号は2026年7月27日時点で未割り当て）
- CVSS 4.0スコア: 8.7
- 対象製品: n8n（自己ホスト版）
- 影響バージョン: <2.31.5、>=2.32.0,<2.32.1
- 修正バージョン: 2.31.5、2.32.1
- 悪用条件: ワークフロー作成・編集権限を持つ有効なアカウント
- 発見経緯: 先行脆弱性CVE-2026-27577のパッチバイパスとしてSecurity Joesが発見
