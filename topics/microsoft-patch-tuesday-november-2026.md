# Microsoft Patch Tuesday 2026年11月

## 概要

Microsoft の2026年11月月例セキュリティ更新（11月10日公開）。修正件数は1,000件超（報道により1,093〜1,259件）、Critical 63件と過去最大級。悪用確認済みゼロデイは Outlook スプーフィング **CVE-2026-124194**（CVSS 6.5、NTLMv2ハッシュ漏えい、CISA KEV 期限11月24日）。その他 Windows LDAP RCE **CVE-2026-119958**（9.8）、Windows Search RCE **CVE-2026-116928**（9.8）、SharePoint **CVE-2026-120002**（9.9）、Exchange RCE **CVE-2026-118207**（8.8）など。
