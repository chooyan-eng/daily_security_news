# Microsoft Patch Tuesday 2026年11月

## 概要

Microsoftが2026年11月10日に公開した月例セキュリティ更新。修正件数は集計により1,093〜1,235件、Critical 63〜66件。実悪用ゼロデイはMicrosoft Outlookのなりすまし脆弱性CVE-2026-124194（CVSS 6.5、NTLMv2ハッシュ漏えい）。ほかにSharePoint Server CVE-2026-120002（権限昇格、Critical）、Exchange Server CVE-2026-118207（RCE）などを修正。
