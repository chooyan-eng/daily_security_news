# Microsoft Patch Tuesday 2026年7月

## 概要

2026年7月14日リリースのMicrosoft月例セキュリティ更新プログラム。単月として過去最多の622件（CVEベース）の脆弱性を修正し、うち59件がCritical。実際に悪用が確認されたゼロデイ2件（AD FS特権昇格 CVE-2026-56155、SharePoint特権昇格 CVE-2026-56164）と、公開済みだが悪用未確認のBitLockerバイパスCVE-2026-50661が含まれる。

**同一性の判断に役立つ情報：**
- 更新プログラムリリース日: 2026-07-14
- 主要CVE: CVE-2026-56155（AD FS EoP、悪用実績あり）、CVE-2026-56164（SharePoint EoP、悪用実績あり）、CVE-2026-50661（BitLockerバイパス、公開済み）
- 修正総数: 622件（過去最多）
- Criticalの件数: 59件
