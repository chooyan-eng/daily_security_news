# Microsoft Patch Tuesday 2026年7月

## 概要

2026年7月14日公開のMicrosoft月例セキュリティ更新（Patch Tuesday）。過去最大となる621件のCVEを修正し、うち2件のゼロデイ（AD FS権限昇格 CVE-2026-56155、SharePoint Server権限昇格 CVE-2026-56164）は実際の攻撃での悪用が確認されている。SharePoint、RDP、Hyper-Vにも重大な脆弱性が含まれる。CISAは即日この2件をKEVカタログに追加。

**同一性の判断に役立つ情報：**
- 公開日: 2026年7月14日
- 修正CVE件数: 621件（過去最大）
- 悪用済みゼロデイ: CVE-2026-56155（AD FS）、CVE-2026-56164（SharePoint Server）
- CISA KEV追加: 2026年7月14日
