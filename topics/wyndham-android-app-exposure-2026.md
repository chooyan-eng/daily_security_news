# Wyndham Androidアプリ ハードコード認証情報による顧客データ露出（2026年11月）

## 概要

ホテル大手WyndhamのAndroidアプリにハードコードされたパスワードにより、Salesforce上の社内データベース（顧客氏名、メールアドレス、会員番号、ログイントークン、数百万エントリ）にアクセス可能だった事案。What Security の Robert Wiggins 氏が発見し、TechCrunch経由で通知、2026年11月9日報道。同社は認証情報を失効、悪用の証拠なしと説明。同氏によるApplebee'sアプリでの同種発見に続くもの。
